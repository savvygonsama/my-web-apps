# 👊 권왕(拳王): 맨손의 강호 (베타 1)

로블록스용 무협 오픈 월드 격투 게임입니다. 무기 없이 **맨손 권법 일곱 가지** 중 하나를 익혀 강호를 누비고,
칼·창·곤봉을 든 산적과 자객을 상대로 **합을 겨룹니다**. 흘리고, 균형을 무너뜨리고, 한 방을 꽂으세요.

- 동작은 애니메이션 파일 없이 **관절을 코드로 직접** 움직입니다 (업로드할 것이 없습니다)
- 누르는 순간 내 몸이 먼저 움직이고, 맞힌 상대를 서버가 확인합니다 (기다림 없는 조작감)
- 맞는 순간 둘 다 멈칫(히트스톱), 화면 흔들림, 불꽃·충격파, 손발 잔상, 피해 숫자

## 바로 해 보기

1. `kwonwang.rbxlx`를 Roblox Studio로 엽니다
2. ▶ 플레이. 처음 들어오면 권법 창이 뜹니다. 하나 고르면 공짜로 배웁니다
3. 스튜디오에서는 **🧪 테스트** 메뉴가 보입니다 (은자·능력치·숙련 최대, 적·보스 부르기)

기록 저장은 게임을 올린 뒤 **게임 설정 → 보안 → Studio에서 API 서비스 사용**을 켜면 됩니다 (DataStore `Kwonwang_v1`).

## 조작

| 키 | 하는 일 |
|---|---|
| 클릭 | 연타 (권법마다 네 번 이어짐). 누른 걸 줄 세워 두었다가 앞 동작이 끝나면 바로 나간다 |
| 우클릭 | 강한 한 방 (천룡파천장은 누르고 있다 놓기: 모은 만큼 큰 장풍) |
| E · R | 기술 (R은 숙련 3에 열림) |
| G | 오의 (숙련 5, 내공 100) |
| Q | 대시 (0.22초 무적, 무영귀각은 두 번) |
| F | 막기. **맞기 직전에 누르면 흘리기** |
| Space (공중) | 두 번 뛰기 |
| H | 금창약 (체력 40%) |
| T (가까이) | 사부·수련·상점 |
| Tab | 능력치 창 |

휴대폰에서는 오른쪽 아래 둥근 버튼이 생깁니다. 치면 가까운 적(카메라 쪽 75도, 14칸 안) 쪽으로 몸이 저절로 돕니다.

## 합을 겨루는 법

| 이름 | 무엇 |
|---|---|
| 🛡 막기 | 앞에서 오는 공격의 피해를 85% 줄인다. 대신 내 균형이 찬다 |
| 流 흘리기 | 막기를 누른 직후 0.2초 (태허유수권 0.32초) 안에 맞으면 피해 없이 흘려 낸다. 친 쪽이 휘청이고 균형이 크게 찬다 |
| 🟧 균형 | 막거나 흘려질 때 찬다. 1.5초 맞지 않으면 줄어든다 |
| 破 파훼 | 균형이 꽉 차면 1.6초 무릎이 꺾인다. 다음 한 방이 1.6배 |
| 激 격돌 | 서로 같은 순간(0.12초 안)에 치면 주먹이 부딪혀 둘 다 튕겨 난다 |
| ⚠ 붉은 공격 | 적의 붉게 빛나는 큰 공격은 막을 수도 흘릴 수도 없다. 대시로 피한다 |

적은 휘두르기 직전 **무기가 반짝입니다**. 그때 F를 누르면 흘립니다.

## 권법 일곱 가지

| 권법 | 고유 장치 | 우클릭 | E | R | 오의 G |
|---|---|---|---|---|---|
| ☯ 태허유수권 (太虛流水拳) | 흘리기 판정이 넓다. 흘릴 때마다 **기류** 1 (최대 3) | 반탄장: 기류만큼 강해짐 | 유수회선: 받아넘기기 자세, 맞으면 저절로 흘리고 되받아침 | 선풍기류: 끌어당기는 소용돌이 | 만류귀종: 물의 용 |
| 🔔 불괴금강신권 (不壞金剛神拳) | **공격 중엔 안 밀리고** 받는 피해 30% 감소. 대시가 느림 | 대력금강장 (균형을 크게 깎음) | 철포삼: 6초 무엇에도 안 밀림, 피해 절반 | 사자후: 주변 기절 | 여래신장: 하늘의 금빛 손바닥 |
| 🌸 매화난무권 (梅花亂舞拳) | 빠르다(1.15배). 끊기지 않게 맞히면 **꽃잎** 쌓임 (최대 20) | 매화일섬: 꽃잎 20이면 만개 폭발 | 낙화연격: 여덟 번 연타 | 암향표: 무적으로 뚫고 지나가며 벰 | 매화만개: 꽃잎 폭풍 |
| 🐉 천룡파천장 (天龍破天掌) | 연타 마지막이 장풍. **누르고 있다 놓는** 장풍 | 항룡장 (모을수록 최대 2.2배) | 항룡유회: 꿰뚫는 용의 기운 | 비룡승천: 올려 쳐 띄움 | 구룡승천: 아홉 용 기둥 |
| 🌑 무영귀각 (無影鬼脚) | **대시 2번**, 등 뒤를 차면 1.6배 | 귀영낙각: 날아차기 | 그림자 걸음: 적 등 뒤로 순간이동 | 귀영난각: 공중 회오리 여섯 번 차기 | 무영천각: 여섯 그림자 |
| ⚡ 벽력신권 (霹靂神拳) | 맞힐 때마다 **전하** 1, 5가 되면 연쇄 번개 (주변 마비) | 벽력일권: 몸을 던지는 직선 주먹 | 뇌전보: 무적 돌진, 지나간 적 마비 | 뇌격: 주변 적에게 벼락 | 천뢰멸: 벼락 폭풍 |
| 🍶 취팔선권 (醉八仙拳) | 움직이거나 치는 중 **25% 저절로 피함**. 막기는 약함 | 취선도: 박치기 돌진 | 취보: 3초 60% 회피 + 피할 때마다 되받아침 | 팔선과해: 돌며 치기 | 취화난무: 불 뿜기 |

첫 권법은 공짜, 그다음은 은자 200 → 500 → 1000 → 2000 → 3500 → 5000. 마을 **권법 전당**의 일곱 사부에게 배웁니다.
숙련도는 그 권법으로 맞힐 때마다 오르고 (최대 10), 레벨마다 그 권법 피해 +3%.

## 강해지기 (수련 반, 실력 반)

능력치는 로그로 완만하게 오릅니다: 배율 = 1 + 0.25 × ln(1 + 능력치 ÷ 20). 100이면 ×1.45, 1000이면 ×1.98, 10000이면 ×2.55.
오래 수련한 쪽이 조금 유리할 뿐, 흘리기와 거리 싸움을 잘하는 쪽이 이깁니다.

| 수련 | 곳 | 능력치 | 하는 법 |
|---|---|---|---|
| 🪨 바위 들기 | 마을 서쪽 수련터 | 💪 근골 (피해) | 고리가 줄어들어 하얀 원에 겹칠 때 Space |
| 🪵 목인장 | 마을 동쪽 수련터 | ❤ 체력 | 나무팔이 들어오는 순간 F |
| 💧 폭포 명상 | 비류 폭포 아래 | 🌀 내공 (내공 회복, 기술 위력) | 숨이 가장 커질 때 Space |
| 🎋 대나무 경공 | 대나무 숲 | 🍃 경공 (이동 속도) | 빛나는 고리 열 개를 차례로 지나간다 |

완벽 = 2배, 좋음 = 1배. 경지가 오를수록 수련 효과 +25%씩, 💊 소환단이면 2배.

**경지**(능력치 합): 삼류 0 → 이류 100 → 일류 400 → 절정 1200 → 초절정 3000 → 화경 7000 → 현경 15000 → 생사경 30000. 머리 위 이름표에 보입니다.

## 강호 (오픈 월드)

| 지역 | 자리 | 있는 것 |
|---|---|---|
| 청운 마을 | 가운데 (안전) | 권법 전당, 만물상, 비무대, 수련터 (바위·목인장) |
| 대나무 숲 | 서쪽 | 산적 도객, 창병, 대나무 경공 코스 |
| 흑호채 (산적 소굴) | 북쪽 | 산적 도객, 곤봉 산적, 창병, 보스 **흑호** |
| 비류 폭포 계곡 | 동쪽 | 쌍도 자객, 곤봉 산적, 폭포 명상, 보스 **혈랑** |

| 적 | 무기 | 특징 |
|---|---|---|
| 산적 도객 | 도 | 베기, 연속 베기, ⚠ 내려찍기 |
| 창병 | 창 | 멀리서 찌르기, 휘두르기, ⚠ 돌진 찌르기 |
| 곤봉 산적 | 곤봉 | 크고 느리다. 넓은 후려치기, ⚠ 땅 내려치기 |
| 쌍도 자객 | 쌍도 | 빠른 삼연격, 기습 찌르기 |
| 👹 흑호 · 산적 두목 | 대도 | 삼연참, 회전 베기, ⚠ 뛰어 내려찍기. 체력 절반 아래면 분노 (빨라지고 돌진 추가) |
| 👹 혈랑 · 자객 우두머리 | 쌍도 | 오연격, 등 뒤로 순간이동, ⚠ 혈류참. 분노하면 회오리 추가 |

적은 근처(170칸)에 사람이 있을 때만 움직이고, 쓰러지면 25초 뒤 (보스는 2분 뒤) 다시 나타납니다.
가끔 내가 치기 시작할 때 막습니다 (보스는 더 자주).

## 소리 바꾸기

지금은 로블록스에 들어 있는 기본 소리를 씁니다. 더 좋은 타격음이 있으면 `src/client/KwonClient/Fx.lua` 맨 위 `SOUNDS` 표의 번호만 바꾸면 됩니다 (`rbxassetid://번호`).

## 파일

| 파일 | 하는 일 |
|---|---|
