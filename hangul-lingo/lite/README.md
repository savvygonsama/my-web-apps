# ハングリンゴ Lite (한글링고 라이트)

일본인이 한국어를 배우는 앱입니다. [스틸링고 Lite](../../steel-lingo/lite/)를 그대로 뒤집었습니다 —
화면의 설명글은 일본어, 배우는 말은 한국어, 후리가나 자리에는 **한글 위 가타카나**가 들어갑니다.

## 내려받기

| 무엇 | 어떻게 |
|---|---|
| **`hangul-lingo-lite.html`** | 파일 하나로 끝나는 판입니다. 위 목록에서 파일을 누르고 **Download raw file** 버튼을 누른 뒤, 내려받은 파일을 더블클릭하면 브라우저에서 열립니다. 글꼴이 안에 들어 있어 7MB쯤 되고, 인터넷 없이도 그대로 돌아갑니다. |
| `index.html` + `fonts/` + `sw.js` | 웹에 올려 쓰는 판입니다. 홈 화면에 **설치**해서 앱처럼 쓸 수 있습니다. 폴더째 있어야 돌아갑니다. |

받은 사람에게 보낼 때는 **`hangul-lingo-lite.html` 한 개**만 보내면 됩니다.

## 들어 있는 것

5과 — 큰비 / 지하철 / 편의점 / 벚꽃 / 식당.
1~2과는 「-ㅂ니다」, 3과부터 「-아/어요」로 어미를 차례로 풉니다.

한 회차는 이렇게 흘러갑니다.

1. **今日の話** — 쉬운 한국어 네 문장
2. **今日おぼえることば** — 단어 6개와 예문 6개, 조각별 뜻·역할·읽기
3. **模擬会話** — 여섯 턴. 내 대사는 조각을 순서대로 눌러 맞춥니다
4. **軽くたしかめ** — 8문항
5. **今日の韓国の話** — 칼럼 (장마 · 환승 · 봉투 · 꽃놀이 · 반찬)

## 소리에 대해

원어민 녹음본은 아직 없고, **브라우저에 깔린 한국어 음성**을 씁니다.
소리가 안 나면 앱 안에 윈도우·아이폰·안드로이드별 설치 방법이 안내로 뜹니다.

> 카카오톡·LINE으로 받은 링크를 그 앱 안에서 열면 소리가 나지 않습니다.
> 화면에 뜨는 안내대로 크롬·사파리로 열어 주세요.

## 가타카나에 대해

한국어에는 가타카나로 적을 수 없는 소리가 있습니다(ㅓ와 ㅗ, ㄱ/ㅋ/ㄲ, 받침소리).
그래서 가타카나는 **길잡이**일 뿐이고, 앱도 첫 화면에서 그렇게 밝히고 있습니다.
낱말 하나하나의 읽기를 붙여 놓았으므로 이어 읽으면 소리가 달라집니다 —
한국 + 에서는 은 실제로 **ハングゲソヌン**입니다.
이어 읽은 진짜 소리는 예문의 **「ばらして見る」** 안 「読み」 칸에 나옵니다.
