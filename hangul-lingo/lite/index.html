ハングリンゴLite

韓国語をはじめたばかりの方のための入り口です。今日のことばを例文といっしょに覚え、そのことばが行き交う短い会話をかけらから組み立てます。今日ひと足、明日もうひと足。そうやって少しずつ積んでいけば大丈夫です。

ハングルの上のカタカナは目安です。ことば一つずつの読みを載せているので、続けて言うと音が変わります — 「한국」＋「에서는」は、つなげるとハングゲソヌン。つないだときの本当の音は、例文のばらして見るにある「読み」の欄に出ます。最後は🔊を押して、耳で直してください。

いまアプリのなかのブラウザで開いています。 ここでは韓国語の音が出ません。
🔇 韓国語の音声が入っていません

Windows — 設定 → 時刻と言語 → 言語と地域 → 言語の追加 → 한국어(韓国語) → 追加するとき音声にチェック。入れたあとブラウザを完全に閉じてから開き直すと認識されます。

iPhone — 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 韓国語 を追加します。たいていは何もしなくても鳴ります。

Android — Google 音声サービスで韓国語をダウンロードすると鳴ります。

音が不自然に聞こえるときは声を替えてみてください。自然な順は Siri/高品質 > Google 한국의 > Edge の InJoon・SunHi です。Windows 標準の Heami はいちばん機械的に聞こえます — Microsoft Edge で開くとニューラル音声が使えて、ずっと聞きやすくなります。
