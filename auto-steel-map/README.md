# 자동차강판 부품 지도

자동차강판 판매 직원 교육용. 차 한 대를 위에서부터 쪼개 들어가며 부품마다 품종·강도·두께·통용 규격명을 익힙니다.

지금 판은 **내연차편**입니다(`app.html` 의 `MODE`). 전기차 전용 부품(배터리 케이스·모터 코어)은 데이터에 들어 있지만 화면에서는 숨겨 두었고, 공통 부품 카드에는 「전기차에서는」 항목으로 차이를 적었습니다.

- `index.html` : 배포용. 이 파일 하나만 열면 됩니다 (오프라인 동작)
- `data.js` : 부품·규격·용어 데이터 원본. **검수·수정은 여기서**
- `app.html` : 화면 틀
- `img/` : 분류 화면 그림
- `build.sh` : `data.js` + `app.html` + `img/` → `index.html`

## 상태

- 모든 값은 **일반적인 업계 경향 초안**입니다. 사내 TS 검수 전에는 배포하지 마세요.
- 영업 항목(구매 주체·공급 경로·대당 사용량·기회와 약점)은 비어 있습니다. `PARTS` 각 항목에 `sales:{buyer, route, kg, swot}` 로 채웁니다.
- 그림(`img/*.webp`)은 이미지 생성 AI로 만든 개념도입니다(`IMAGE_PROMPTS.md`). 핀 좌표는 `data.js` 의 `IMGS` 에서 고칩니다. `old_` 로 시작하는 6장(휠·스티어링·제동·시트·EV·엔진)은 1판 저해상도 그림이라, 새 그림이 오면 바꿔 끼우고 `IMGS` 의 파일 이름만 고치면 됩니다.
- 앱의 「안내」 화면에서 검수용 CSV(엑셀)를 내려받을 수 있습니다.
