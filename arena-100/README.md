# ⚔ ARENA 100 (베타)

로블록스용 투기장 액션 클리커 게임입니다. 직접 싸워서 스테이지를 뚫고, 떨어진 칼을 합성해 100등급까지 올라갑니다.
이긴 스테이지는 켜 두면 알아서 반복 사냥합니다. 무기마다 스킬 둘과 필살기가 있고, 적은 7종이 각자 다른 패턴으로 덤빕니다.
등급이 오를수록 무기와 캐릭터가 화려해집니다.

> 베타 버전입니다. 타이쿤(투기장 시설), 구간 돌파, 유료 상품은 아직 들어 있지 않습니다.

## 바로 해 보기

### 방법 1. 게임 파일 열기 (가장 쉬움)

1. 이 폴더의 [`arena-100.rbxlx`](arena-100.rbxlx)를 엽니다
2. 오른쪽 위 **Download raw file** 버튼으로 내려받습니다
3. 내려받은 파일을 더블클릭하면 로블록스 스튜디오에서 열립니다
4. 위쪽 **Play** 버튼(▶)을 누르면 바로 시작됩니다

### 방법 2. 스크립트 직접 붙여 넣기

스튜디오에서 **Baseplate** 템플릿으로 새 게임을 만든 다음, 아래 아홉 개를 만들고 내용을 그대로 붙여 넣습니다.
이름과 위치가 정확히 같아야 합니다. "안에"라고 적힌 것은 그 스크립트를 오른쪽 클릭해서 그 아래에 만듭니다.

| 넣을 곳 (탐색기 창) | 만들 것 | 이름 | 붙여 넣을 파일 |
|---|---|---|---|
| ReplicatedStorage | ModuleScript | `GameConfig` | [`src/shared/GameConfig.lua`](src/shared/GameConfig.lua) |
| ReplicatedStorage | ModuleScript | `WeaponBuilder` | [`src/shared/WeaponBuilder.lua`](src/shared/WeaponBuilder.lua) |
| ServerScriptService | Script | `ArenaServer` | [`src/server/ArenaServer/init.server.lua`](src/server/ArenaServer/init.server.lua) |
| `ArenaServer` 안에 | ModuleScript | `WorldBuilder` | [`src/server/ArenaServer/WorldBuilder.lua`](src/server/ArenaServer/WorldBuilder.lua) |
| `ArenaServer` 안에 | ModuleScript | `EnemyBuilder` | [`src/server/ArenaServer/EnemyBuilder.lua`](src/server/ArenaServer/EnemyBuilder.lua) |
| `ArenaServer` 안에 | ModuleScript | `EnemyAI` | [`src/server/ArenaServer/EnemyAI.lua`](src/server/ArenaServer/EnemyAI.lua) |
| `ArenaServer` 안에 | ModuleScript | `Skills` | [`src/server/ArenaServer/Skills.lua`](src/server/ArenaServer/Skills.lua) |

로비, 투기장, 조명, 화면 UI는 스크립트가 알아서 만듭니다. 따로 지을 것은 없습니다.

### 저장 기능 켜기

저장은 로블록스 서버(DataStore)를 씁니다. 스튜디오에서 테스트할 때 저장까지 확인하려면:

1. **File → Publish to Roblox**로 게임을 한 번 올립니다
2. **Home → Game Settings → Security**에서 **Enable Studio Access to API Services**를 켭니다

이걸 안 켜도 게임은 돌아갑니다. 화면에 "저장이 꺼져 있어요"라는 알림만 뜨고, 기록이 남지 않습니다.

### 아바타 설정

베기 동작은 R15 아바타 기준입니다. **Game Settings → Avatar**에서 아바타 종류를 **R15**로 두세요.

## 조작

| | PC | 휴대폰 |
|---|---|---|
| 공격 | 마우스 왼쪽 클릭 (누르고 있으면 연속 공격) | 오른쪽 아래 ⚔ 버튼 누르고 있기 |
| 대시 (잠깐 무적) | Q 또는 Shift | 💨 버튼 |
| 무기 스킬 | E, F | 스킬 버튼 둘 |
| 필살기 (게이지가 다 차면) | R | 💥 버튼 |

공격하면 가장 가까운 적에게 알아서 다가갑니다. 보스가 바닥에 빨간 원을 그리면 대시로 피하세요.
로비의 붉은 문 앞에 서면 **투기장 입장**, 용광로 모루 앞에서는 **합성하기**, 허수아비 앞에서는 **훈련하기** 버튼이 뜹니다.

## 게임 구조

### 등급 100단계
Trash에서 시작해 The Omnipotent Origin Beyond Existence까지 갑니다. 스테이지 번호가 곧 적의 등급이고,
이긴 가장 높은 등급이 머리 위 칭호가 됩니다. 10스테이지마다 보스가 나옵니다.

| 구간 | 등급 | 합성에 필요한 개수 |
|---|---|---|
| 풋내기 | 1~20 | 2개 |
| 투기장 강자 | 21~40 | 3개 |
| 지배자와 전설 | 41~60 | 4개 |
| 태초와 신성 | 61~80 | 5개 |
| 우주 | 81~93 | 6개 |
| 최종 | 94~100 | 6개 |

### 무기 5계열

| 계열 | 특징 |
|---|---|
| 대검 | 공격력 높음, 느림 |
| 쌍검 | 공격 속도 빠름 |
| 장검 | 앞쪽으로 길게, 최대 3명 |
| 단검 | 치명타 잘 터짐 |
| 낫 | 내 주위를 한 바퀴 베고 흡혈, 기본 공격력은 낮음 |

### 희귀도 순환
등급마다 다섯 계열의 희귀도(일반·고급·희귀·영웅·전설)가 한 칸씩 돌아갑니다.

| 등급 | 전설 | 영웅 | 희귀 | 고급 | 일반 |
|---|---|---|---|---|---|
| 1 | 대검 | 쌍검 | 장검 | 단검 | 낫 |
| 2 | 낫 | 대검 | 쌍검 | 장검 | 단검 |
| 3 | 단검 | 낫 | 대검 | 쌍검 | 장검 |
| 4 | 장검 | 단검 | 낫 | 대검 | 쌍검 |
| 5 | 쌍검 | 장검 | 단검 | 낫 | 대검 |

같은 계열끼리 합성하면 다음 등급이 되고, 다음 등급에서는 희귀도가 바뀝니다. 같은 계열이면 합성 결과가 항상 더 셉니다.

### 무기 스킬
필살기와 별개로 계열마다 스킬이 둘씩 있습니다. 재사용 대기 시간이 지나면 다시 쓸 수 있습니다.

| 무기 | E | F |
|---|---|---|
| 대검 | 🐗 파쇄 돌격: 돌진해서 부딪힌 적을 날리고 2초 기절 | 🌀 대검 투척: 회전하는 대검이 갔다가 돌아오며 두 번 벤다 |
| 쌍검 | 🎯 표식 연격: 표식 남긴 적을 6번 베면 폭발 | 👥 잔상 돌파: 꿰뚫고 지나간 뒤 잔상이 한 번 더 벤다 |
| 장검 | 🌙 검기 발사: 방패도 뚫는 초승달 검기 | 🛡 반격 자세: 1.2초 안에 맞으면 막고 주위를 크게 벤다 |
| 단검 | ☠ 맹독 칼날: 6초 동안 베는 적마다 독 | 💨 연막 순보: 2초 무적, 다음 공격은 3배 확정 치명타 |
| 낫 | ⛓ 사슬 낚아채기: 앞쪽 적을 끌어와 기절 | 💀 망자의 원: 4초 동안 원 안의 적을 베고 나를 치유 |
| 올라운더 | ⚔ 만검 강림: 하늘에서 검 12자루가 꽂힌다 | ⏳ 시공 정지: 3초 동안 모든 적의 시간을 멈춘다 |

### 적 7종과 웨이브
스테이지가 오를수록 적 종류, 웨이브당 수(3~7명), 웨이브 수(1~3)가 늘어납니다. 새 적이 처음 나오는 스테이지에는 그 적이 꼭 나옵니다.
모든 공격은 바닥이나 몸에 먼저 빨간 경고가 뜨고, 경고 안에서 밝은 원이 차오르면 곧 들어옵니다. 웨이브를 깨면 체력 30%를 회복합니다.

| 적 | 처음 나오는 곳 | 생김새 | 패턴 |
|---|---|---|---|
| 돌격병 | 1 | 투구, 칼 | 다가와서 벤다 |
| 궁수 | 4 | 두건, 활, 화살통 | 거리를 벌리고 빨간 선으로 조준한 뒤 화살을 쏜다 |
| 방패병 | 8 | 투구, 큰 방패, 창 | 앞에서 오는 공격을 70% 막는다 |
| 돌진꾼 | 12 | 큰 몸, 뿔, 가시 몽둥이 | 빨간 길을 그리고 그 길로 돌진한다 |
| 자폭병 | 16 | 작은 몸, 고글, 등에 화약통 | 붙으면 1초 뒤 터진다 |
| 주술사 | 21 | 뾰족 모자, 로브, 빛나는 지팡이 | 멀리서 발밑에 불길 원을 띄운다 |
| 암살자 | 26 | 검은 두건, 붉은 목도리, 쌍단검 | 내 등 뒤로 순간이동해 찌른다 |

보스는 번호마다 다른 종류의 모습에 왕관과 망토를 두르고, 내려찍기·돌진·회전 베기·운석·부하 소환 중 정해진 조합을 번갈아 씁니다.
뒤로 갈수록 쓰는 기술이 늘어납니다.

### 필살기
때릴 때마다 게이지가 차고, 어떤 무기든 약 9초 동안 싸우면 가득 찹니다.

| 무기 | 필살기 | 하는 일 |
|---|---|---|
| 대검 | 대지 가르기 | 앞으로 땅을 갈라 일직선의 적을 모두 벱니다 (공격력 8배) |
| 쌍검 | 칼날 폭풍 | 2.5초 동안 주위를 쉴 새 없이 벱니다 |
| 장검 | 일섬 | 앞으로 순간 돌진하며 지나간 자리의 적을 모두 벱니다 (7배) |
| 단검 | 그림자 처형 | 가장 강한 적 뒤로 순간이동해 치명타 5연타 |
| 낫 | 영혼 수확 | 넓은 원 안의 적을 베고 체력 30% 회복 |
| 올라운더 | 천지개벽 | 투기장의 모든 적을 베고 체력 30% 회복 (10배) |

필살기를 쓰는 동안 잠깐 무적이고, 자동 반복 중에는 알아서 씁니다.

### 치명타
모든 무기가 5% 확률로 1.8배, 단검은 30% 확률로 2.5배입니다. 치명타가 터지면 숫자가 크게 튀어나오고,
보스가 아닌 적은 멀리 날아갑니다.

### 강할수록 화려하게
무기와 내 캐릭터는 장착한 무기의 구간에 따라 단계적으로 바뀝니다.

| 구간 | 무기 | 캐릭터 |
|---|---|---|
| 1 | 쇠 칼날 | |
| 2 | + 희귀도 색 보석, 휘두를 때 궤적 | |
| 3 | + 칼날 가운데 빛나는 홈, 은은한 빛 | 오라 |
| 4 | + 유리 칼날, 반짝이 파티클 | 오라 진하게 |
| 5 | + 우주 칼날, 별 파티클 | 오라 + 몸에서 빛 |
| 6 | + 빛나는 칼날, 무지개 궤적 | 무지개 오라 |

전설 희귀도는 금빛 반짝임이 더해집니다. 적도 구간이 오를수록 무기를 들고 오라를 두르며, 보스는 왕관을 씁니다.

### 올라운더
100등급 대검·쌍검·장검·단검·낫을 하나씩 모아 합치면 최종 무기 **올라운더**가 됩니다.

### 자동 반복
한 번 이긴 스테이지에서 전투력이 **권장 전투력의 1.5배 이상**이면 🔁 버튼이 열립니다.
켜 두면 이기는 대로 같은 스테이지를 계속 반복합니다.

### 훈련
코인으로 공격력과 체력을 레벨당 8%씩 올립니다. 무기를 바꿔도 남습니다.

## 수치 바꾸기

밸런스는 전부 [`src/shared/GameConfig.lua`](src/shared/GameConfig.lua) 한 파일에 있습니다.
등급 이름, 무기 계열 수치, 희귀도 배율, 합성 개수, 적 체력과 공격력, 보상 코인을 여기서 고칩니다.

## 로비

노을빛 대리석 광장에 횃불 기둥 12개가 둘러서 있고, 기둥 여섯 개에는 구간 깃발이 걸려 있습니다.
반딧불이 떠다니고, 머리 위로 등불 열 개가 둥실 떠 있습니다.

| 시설 | 위치 | 내용 |
|---|---|---|
| 투기장 입구 문 | 앞 | 불티가 날리는 붉은 문. 앞에 서면 스테이지 창이 열린다 |
| 🔨 합성 용광로 | 오른쪽 | 불을 뿜는 화로, 돌아가는 톱니바퀴, 빛나는 약물 탱크, 모루. 누가 합성하면 화로가 번쩍이고 톱니가 빨라진다 (모두에게 보인다) |
| 💪 훈련장 | 왼쪽 | 허수아비 셋과 무기 걸이 |
| ⚔ 무기 전시대 | 뒤 | 1~6구간 전설 무기가 받침대 위에서 떠서 돈다 |
| 황금 검투사 동상 | 왼쪽 앞 | 올라운더를 든 챔피언 |
| 🏆 명예의 전당 | 오른쪽 앞 | 이 서버 최고 기록 5명 |

## 연출

- 타격마다 불꽃, 치명타는 큰 숫자와 폭발, 적은 날아감
- 적이 쓰러지면 몸이 터지고 영혼이 하늘로. 보스는 거대한 빛기둥과 연쇄 폭발
- 3번 이상 이어 때리면 콤보 숫자. 10·25·50·100에서 색이 바뀜
- 전투 시작 빛기둥, 웨이브와 보스 등장 배너, 첫 승리 때 RANK UP 축포
- 맞으면 화면 가장자리가 붉게 번쩍이고, 체력 30% 아래에서는 숨 쉬듯 깜빡임
- 대시하면 내 몸 모양 잔상이 남음

## 파일 구성

```
arena-100/
├── arena-100.rbxlx                  스튜디오에서 바로 여는 게임 파일
├── default.project.json             Rojo 프로젝트 설정
└── src/
    ├── shared/
    │   ├── GameConfig.lua           수치와 데이터 (서버·클라이언트 공용)
    │   └── WeaponBuilder.lua        무기 모양, 등급별 효과, 오라 (공용)
    ├── server/ArenaServer/
    │   ├── init.server.lua          전투, 웨이브, 필살기, 합성, 저장
    │   ├── WorldBuilder.lua         조명, 로비(용광로·전시대·훈련장), 투기장
    │   ├── EnemyBuilder.lua         적 7종의 생김새
    │   ├── EnemyAI.lua              적 종류별 행동, 보스 기술
    │   └── Skills.lua               무기 스킬 12종
    └── client/ArenaClient/
        ├── init.client.lua          화면 UI와 조작
        └── Effects.lua              베기 궤적, 치명타, 스킬·필살기·적 공격 연출, 효과음
```

`src`를 고친 뒤 게임 파일을 다시 만들려면 [Rojo](https://rojo.space)로 `rojo build default.project.json -o arena-100.rbxlx`를 실행합니다.
