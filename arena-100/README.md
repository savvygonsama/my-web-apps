# ⚔ ARENA 100 (베타)

로블록스용 투기장 액션 클리커 게임입니다. 직접 싸워서 스테이지를 뚫고, 떨어진 칼을 합성해 100등급까지 올라갑니다.
이긴 스테이지는 켜 두면 알아서 반복 사냥합니다. 무기마다 스킬 둘과 필살기가 있고, 적은 12종이 각자 다른 패턴으로 덤빕니다.
등급이 오를수록 무기와 캐릭터가 화려해집니다. 100스테이지 뒤에는 초월 스테이지 100층이 더 있고,
무기 강화(+10), 아우라 30종, 킬 이펙트 30종으로 힘을 키워 뚫습니다.

> 베타 버전입니다. 타이쿤(투기장 시설), 구간 돌파, 유료 상품은 아직 들어 있지 않습니다.

## 바로 해 보기

### 방법 1. 게임 파일 열기 (가장 쉬움)

1. 이 폴더의 [`arena-100.rbxlx`](arena-100.rbxlx)를 엽니다
2. 오른쪽 위 **Download raw file** 버튼으로 내려받습니다
3. 내려받은 파일을 더블클릭하면 로블록스 스튜디오에서 열립니다
4. 위쪽 **Play** 버튼(▶)을 누르면 바로 시작됩니다

### 🧪 테스트 계정 (만렙)

스튜디오에서 ▶ Play로 들어가거나, 게임을 올린 뒤 **게임 주인**으로 들어가면 테스트 계정이 됩니다.

- 1~200 스테이지가 모두 열려 있고 코인이 무한입니다
- 계열마다 1·15·30·45·60·75·90·100등급 무기를 3개씩, 올라운더 1개를 들고 시작합니다. 100등급과 올라운더는 +10 강화
- 아우라 30종과 킬 이펙트 30종을 모두 갖고 있고, 30단계를 장착한 채 시작합니다
- 왼쪽 메뉴의 **🧪 테스트** 창에서 등급(±1, ±10)과 계열을 고르면 3D 미리보기(+10 모습)가 바로 바뀌고,
  **이 무기 받고 장착**, **이 등급 스테이지 도전**, **초월 스테이지 (등급+100)**, **필살기 게이지 채우기**, **무적**, **쿨타임 없음**,
  **장착 무기 강화 +0/+3/+5/+7/+10**, **아우라·킬 이펙트 ◀ ▶**를 쓸 수 있습니다
- 테스트 계정의 기록은 저장하지 않습니다 (실제 기록을 덮어쓰지 않게)
- 정식 공개 전에는 [`GameConfig.lua`](src/shared/GameConfig.lua)의 `Config.TEST_MODE`를 `false`로 바꾸세요

### 저장 기능 켜기

저장은 로블록스 서버(DataStore)를 씁니다. 스튜디오에서 테스트할 때 저장까지 확인하려면:

1. **File → Publish to Roblox**로 게임을 한 번 올립니다
2. **Home → Game Settings → Security**에서 **Enable Studio Access to API Services**를 켭니다

이걸 안 켜도 게임은 돌아갑니다. 화면에 "저장이 꺼져 있어요"라는 알림만 뜨고, 기록이 남지 않습니다.

### 아바타 설정

베기 동작은 R15 아바타 기준입니다. **Game Settings → Avatar**에서 아바타 종류를 **R15**로 두세요.

## 게임 구조

### 등급 100단계
Trash에서 시작해 The Omnipotent Origin Beyond Existence까지 갑니다. 스테이지 번호가 곧 적의 등급이고,
이긴 가장 높은 등급이 머리 위 칭호가 됩니다. 10스테이지마다 보스가 나옵니다.

| 구간 | 등급 | 합성에 필요한 개수 |
|---|---|---|
| 풋내기 | 1~20 | 2개 |
| 투기장 강자 | 21~40 | 3개 |
| 지배자와 전설 | 41~60 | 4개 |
| 태초와 신성 | 61~80 | 5개 |
| 우주 | 81~93 | 6개 |
| 최종 | 94~100 | 6개 |

### 초월 스테이지 (101~200)
100스테이지를 깨면 **BEYOND 1**부터 **BEYOND 100**까지 100층이 더 열립니다. 한 층마다 적이 6.5%씩 강해지고,
웨이브는 최대 4개, 웨이브당 적은 최대 10명입니다. 적은 검은 뿔과 무지개 기운을 두르고, 투기장은 무지개 입자로 물듭니다.
무기 등급은 100이 끝이라, 여기서부터는 **강화·아우라·킬 이펙트**와 훈련으로 힘을 키워야 합니다.
초월 스테이지에서는 100등급 무기가 떨어집니다 (올라운더 재료).

### 무기 5계열

| 계열 | 특징 |
|---|---|
| 대검 | 공격력 높음, 느림 |
| 쌍검 | 공격 속도 빠름 |

등급마다 다섯 계열의 희귀도(일반·고급·희귀·영웅·전설)가 한 칸씩 돌아갑니다.

| 등급 | 전설 | 영웅 | 희귀 | 고급 | 일반 |
|---|---|---|---|---|---|
| 1 | 대검 | 쌍검 | 장검 | 단검 | 낫 |
| 2 | 낫 | 대검 | 쌍검 | 장검 | 단검 |
| 3 | 단검 | 낫 | 대검 | 쌍검 | 장검 |
| 4 | 장검 | 단검 | 낫 | 대검 | 쌍검 |

같은 계열끼리 합성하면 다음 등급이 되고, 다음 등급에서는 희귀도가 바뀝니다. 같은 계열이면 합성 결과가 항상 더 셉니다.

### 적 12종과 웨이브
스테이지가 오를수록 적 종류, 웨이브당 수(3~7명), 웨이브 수(1~3)가 늘어납니다. 새 적이 처음 나오는 스테이지에는 그 적이 꼭 나옵니다.
모든 공격은 바닥이나 몸에 먼저 빨간 경고가 뜨고, 경고 안에서 밝은 원이 차오르면 곧 들어옵니다. 웨이브를 깨면 체력 30%를 회복합니다.

| 적 | 처음 나오는 곳 | 생김새 | 패턴 |
|---|---|---|---|
| 돌격병 | 1 | 투구, 칼 | 다가와서 벤다 |
| 궁수 | 4 | 두건, 활, 화살통 | 거리를 벌리고 빨간 선으로 조준한 뒤 화살을 쏜다 |
| 방패병 | 8 | 투구, 큰 방패, 창 | 앞에서 오는 공격을 70% 막는다 |
| 돌진꾼 | 12 | 큰 몸, 뿔, 가시 몽둥이 | 빨간 길을 그리고 그 길로 돌진한다 |
| 자폭병 | 16 | 작은 몸, 고글, 등에 화약통 | 붙으면 1초 뒤 터진다 |
| 주술사 | 21 | 뾰족 모자, 로브, 빛나는 지팡이 | 멀리서 발밑에 불길 원을 띄운다 |
| 암살자 | 26 | 검은 두건, 붉은 목도리, 쌍단검 | 내 등 뒤로 순간이동해 찌른다 |
| 골렘 | 33 | 바위 갑옷, 빛나는 금, 바위 주먹 | 느리고 단단하다. 제자리 땅을 내려쳐 둘레를 터뜨린다 |
| 망령 | 42 | 반투명 수의, 유령 꼬리, 낫 | 몸이 흐려진 동안은 공격이 통하지 않는다 (MISS) |
| 분열체 | 52 | 초록 점액 몸, 빛나는 핵 | 쓰러지면 작은 분열체 둘로 갈라진다 |
| 사제 | 62 | 흰 관, 로브, 황금 후광, 십자 지팡이 | 멀리서 주위 적의 체력을 15% 회복시킨다. 먼저 잡아야 한다 |
| 흑기사 | 75 | 뿔 투구, 견갑, 망토, 방패, 대검 | 앞 공격을 50% 막고, 빨간 길을 그린 뒤 세 번 연속 벤다 |

적 체력과 공격력은 이전보다 35% 세졌습니다 (보스 30%). 적은 공격 직전에 팔을 들어 올렸다 내려치고, 맞으면 몸이 뒤로 젖혀집니다.

**★정예**: 40스테이지부터 특성 하나를 단 정예가 섞여 나옵니다 (40스테이지 8%에서 점점 늘어 최대 55%). 체력 1.5배에 발밑 고리와 색 오라가 붙습니다.

| 특성 | 효과 |
|---|---|
| 신속 | 이동 1.6배 |
| 거대 | 체력 2배, 몸 1.3배 |
| 재생 | 초당 체력 3% 회복 |
| 광폭 | 공격력 1.6배 |

보스는 번호마다 다른 종류의 모습에 왕관과 망토를 두르고, 내려찍기·돌진·회전 베기·운석·부하 소환·**탄막**(사방으로 빛탄 두 바퀴)·**운석비**(투기장 곳곳에 원 10개) 중
정해진 조합을 번갈아 씁니다. 뒤로 갈수록 쓰는 기술이 늘어나고, 초월 보스는 6~7가지를 섞어 씁니다.

### 필살기
때릴 때마다 게이지가 차고, 어떤 무기든 약 9초 동안 싸우면 가득 찹니다.

| 무기 | 필살기 | 하는 일 |
|---|---|---|
| 대검 | 대지 가르기 | 앞으로 땅을 갈라 일직선의 적을 모두 벱니다 (공격력 8배) |
| 쌍검 | 칼날 폭풍 | 2.5초 동안 주위를 쉴 새 없이 벱니다 |
| 장검 | 일섬 | 앞으로 순간 돌진하며 지나간 자리의 적을 모두 벱니다 (7배) |
| 단검 | 그림자 처형 | 가장 강한 적 뒤로 순간이동해 치명타 5연타 |
| 낫 | 영혼 수확 | 넓은 원 안의 적을 베고 체력 30% 회복 |
| 올라운더 | 천지개벽 | 투기장의 모든 적을 베고 체력 30% 회복 (10배) |

필살기를 쓰는 동안 잠깐 무적이고, 자동 반복 중에는 알아서 씁니다.

### 치명타
모든 무기가 5% 확률로 1.8배, 단검은 30% 확률로 2.5배입니다. 치명타가 터지면 숫자가 크게 튀어나오고,
보스가 아닌 적은 멀리 날아갑니다.

### 등급마다 다른 디자인
100등급이 모두 다르게 생겼습니다. 등급이 하나만 올라도 색, 속성, 장식이 바뀝니다.
빛은 은은하게 두고, 뒤로 갈수록 **모양**으로 멋있어집니다: 톱날(15~), 금빛 문양(30~), 갈라진 칼끝(35~),
소용돌이 가드(40~), 늘어진 사슬(55~), 칼끝 너머 떠 있는 칼날 조각(75~).

- **고유 색**: 등급마다 색상을 황금각만큼 돌려서, 바로 옆 등급끼리도 확 달라 보입니다. 100개 모두 주 색이 다릅니다
- **속성 10가지**: 화염 → 서리 → 번개 → 생명 → 그림자 → 성광 → 선혈 → 공허 → 별빛 → 수정이 등급마다 돌아갑니다.
  무기에서 흩날리는 입자와 휘두를 때 연출이 속성마다 다릅니다 (불기둥, 얼음 파편, 번개, 나뭇잎, 그림자 연기, 빛기둥, 핏방울, 블랙홀, 별가루, 수정 고리)
- **재질 13단계**: 녹슨 쇠 → 쇠 → 광택 금속 → 금박 → 거울 강철 → 유리 → 수정 → 얼음 결정 → 흑요석 → 우주 → 심연 수정 → 백금 → 근원
- **장식이 하나씩 늘어남**

| 등급 | 무기에 붙는 것 | 캐릭터에 붙는 것 |
|---|---|---|
| 1~ | 룬 문자 (5등급마다 하나씩, 최대 12) | |
| 3~ | | 속성 오라 |
| 4~ | 가시 (7등급마다 하나씩, 최대 8), 은은한 빛 | |
| 10~ | | 발밑 빛 고리 |
| 12~ | 칼날 둘레를 도는 구슬 (14등급마다 하나씩, 최대 6) | |
| 20~ | 가드 보석 늘어남 | 몸 둘레를 도는 구슬 (최대 6) |
| 21~ | 칼날 빛 테두리 | |
| 25~ | | 몸에서 빛 |
| 30~ | 칼날을 두른 빛 고리 (최대 3겹) | 머리 위 칭호에 입자 |
| 40~ | 별 반짝임 | 두 번째 발밑 고리 |
| 45~ | 가드 날개 | |
| 50~ | 칼끝과 구슬을 잇는 빛줄기 | |
| 60~ | 두 겹 칼날 (반투명 빛 칼날이 감쌈) | |
| 65~ | | 등에 빛 날개 |
| 70~ | 칼날 둘레를 도는 유리 파편 (최대 12) | |
| 80~ | | 머리 위 천사 고리 |
| 85~ | 손잡이를 두른 검 왕관 | |
| 94~ | 무지개 | 무지개 |

크기, 빛 세기, 입자 양, 궤적 길이도 등급마다 조금씩 늘어납니다. 휘두를 때 궤적은 25등급마다 한 겹씩 늘어 최대 5겹이 되고,
40등급부터 발밑 충격파, 60등급부터 화면 떨림, 80등급부터 빛기둥이 더해집니다.

적도 등급마다 몸 색, 재질, 등 가시 개수, 속성 오라가 다르고, 투기장은 스테이지 등급의 색과 속성 입자로 물듭니다.
칭호와 UI의 등급 이름도 모두 그 등급의 두 색으로 칠해집니다.

### 칼날 모양 12종
등급마다 칼날의 생김새 자체가 바뀝니다. 낮은 등급은 단순한 모양 세 가지에서, 등급이 오를수록 고를 수 있는 모양이 늘어나
51등급부터는 12종이 모두 섞입니다. 바로 옆 등급끼리는 모양이 항상 다릅니다.

곧은 날 · 나뭇잎 날 · 식칼 날 · 곡도(휘어진 칼) · 물결 날 · 언월 날 · 빈 틀 날(가운데가 비고 빛나는 심) · 쌍날(두 갈래) ·
갈고리 날 · 초승달 날 · 용골 날(척추뼈 같은 등판) · 수정 날(결정이 돋은 칼날)

낫은 모양에 따라 날이 초승달처럼 크게 휘거나 톱니가 돋고, 30등급부터 반대쪽에 작은 날, 70등급부터 자루 아래에 세 번째 날이 붙습니다.

### 🔥 강화 +1 ~ +10
무기고 창의 **🔥 강화** 버튼으로 장착한 무기를 강화합니다. 단계마다 공격력 +10%, 체력 +5% (+10이면 공격력 2배)이고,
칼에 장식이 하나씩 붙습니다. 100등급 × 강화 11단계라 칼 모습이 1,100가지로 나뉩니다.

| 단계 | 붙는 장식 |
|---|---|
| +1 | 날끝을 따라 희귀도 색으로 빛나는 선 |
| +2 | 칼날 밑동의 문장 보석 |
| +3 | 칼날 양면의 두 줄 룬 홈 |
| +4 | 가드 양쪽 지느러미 |
| +5 | 양면의 화살촉 빛 각인 |
| +6 | 칼날 가운데 솟은 황금 등날 |
| +7 | 칼끝을 도는 빛 구슬 고리 |
| +8 | 칼등을 따라 누운 불꽃 가시 |
| +9 | 칼날을 감싼 빛의 칼집과 별 입자 |
| +10 | 황금 왕관, 칼을 휘감는 번개 두 줄 |

비용은 그 등급 스테이지 한 판 코인의 0.6배에서 시작해 단계마다 1.45배씩 오릅니다.
합성하면 다음 등급 칼이 강화 단계의 **절반**을 물려받습니다.

### ✨ 아우라 30종 · 💀 킬 이펙트 30종
로비 가운데 **아우라 제단**(또는 왼쪽 **✨ 치장** 메뉴)에서 삽니다. 스테이지를 깨면 하나씩 열리고(1~196스테이지), 코인으로 삽니다.
**👁 보기**를 누르면 아우라는 내 분신이 앞에 나타나 입어 보고, 킬 이펙트는 앞에서 터져 봅니다.

| | 힘 | 특수 효과 |
|---|---|---|
| 아우라 | 공격력 최대 3배, 체력 최대 2배 | 4단계부터 **파동**: 몇 초마다 내 주위 적을 때림 (30단계: 1.1초마다 반경 20, 공격력 180%) |
| 킬 이펙트 | 공격력 최대 2.5배 | **처치 폭발**: 적을 잡으면 그 자리가 터져 주위 적에게 피해. 그 폭발로 또 잡으면 **연쇄 폭발** (30단계: 반경 15, 공격력 350%) |

아우라는 단계가 오를수록 쌓입니다: 입자와 빛 → 발밑 고리(2~) → 룬 돌(3~) → 등 뒤 빛 바퀴와 두 번째 고리(6~)
→ 나선으로 감아 오르는 속성 조각(11~) → 날개(15~) → 왕관(19~) → 바닥 육망성과 세 번째 고리(21~) → 몸을 도는 검(24~)
→ 날개 두 쌍(26~) → 손 궤적(27~). 뇌운, 혈월, 블랙홀, 심연의 눈, 초신성 같은 단계는 고유 장식이 더 붙습니다. 아우라는 모두에게 보입니다.

킬 이펙트 30종: 불꽃 터짐, 얼음 파편, 낙뢰, 꽃잎 흩날림, 그림자 흡수, 빛의 기둥, 핏빛 초승달, 공허 붕괴, 별 폭죽, 수정 감옥,
화산 분출, 빙결 쇄도, 뇌전 사슬, 덩굴 휘감기, 망령의 비명, 천벌(하늘에서 빛의 검), 피의 분수, 블랙홀, 유성우, 프리즘 굴절,
용의 불기둥, 절대영도, 천둥신의 망치, 불사조, 차원 절단, 대천사 강림, 혈월, 사건의 지평선, 초신성, 빅뱅.
폭발 범위가 바닥에 고리로 보입니다.

### 올라운더
100등급 대검·쌍검·장검·단검·낫을 하나씩 모아 합치면 최종 무기 **올라운더**가 됩니다.

### 자동 반복
한 번 이긴 스테이지에서 전투력이 **권장 전투력의 1.5배 이상**이면 🔁 버튼이 열립니다.
켜 두면 이기는 대로 같은 스테이지를 계속 반복합니다.

### 훈련
코인으로 공격력과 체력을 레벨당 8%씩 올립니다. 무기를 바꿔도 남습니다.

## 연출

- **모션**: 애니메이션 파일 없이 관절을 직접 움직입니다. 전투 중에는 무기별 자세를 잡고(대검은 두 손, 단검은 낮게 웅크림),
  달리면 몸을 앞으로 기울입니다. 무기별 3단 콤보:

  | 무기 | 1타 | 2타 | 3타 |
  |---|---|---|---|
  | 대검 | 머리 위에서 내려찍기 | 가로 휩쓸기 | 뛰어올라 한 바퀴 회전 베기 |
  | 쌍검 | 오른손 사선 베기 | 왼손 사선 베기 | 두 손 X자 베기 |
  | 장검 | 찌르기 | 올려 베기 | 넓게 가로 베기 |
  | 단검 | 빠른 찌르기 | 역수 베기 | 앞으로 공중제비 찌르기 |
  | 낫 | 크게 휘둘러 거두기 | 머리 위에서 내려 거두기 | 두 바퀴 회전 |
  | 올라운더 | 내려찍기 | 두 바퀴 회전 | 회전 점프 베기 |

  대시는 앞구르기, 스킬과 필살기마다 고유 자세(돌진, 투척, 막기 자세, 하늘로 두 팔, 뛰어올라 내려찍기 등), 이기면 칼을 치켜드는 승리 포즈.
  맞으면 몸이 움찔하고, 타격 연출은 칼이 내려오는 순간에 맞춰 터집니다

- **타격감**: 맞는 순간 휘두르기 동작이 아주 잠깐 멈추는 히트스톱, 화면이 앞으로 당겨졌다 돌아오는 줌 반동,
  맞은 적이 하얗게 번쩍이며 밀려남, 내 반대쪽으로 튀는 불꽃 줄기와 X자 베인 자국. 대검·올라운더는 더 묵직하게
- 치명타는 큰 숫자, 충격 고리, 더 긴 멈춤과 더 큰 반동. 적은 멀리 날아감
- **처치**: 적의 몸이 조각나 사방으로 흩어지고 영혼이 하늘로. 1.2초 안에 이어 잡으면 DOUBLE·TRIPLE·QUADRA·PENTA KILL, 그 뒤로는 RAMPAGE.
  보스는 거대한 빛기둥과 연쇄 폭발
- 3번 이상 이어 때리면 콤보 숫자. 10·25·50·100에서 색이 바뀜
- 전투 시작 빛기둥, 웨이브와 보스 등장 배너, 첫 승리 때 RANK UP 축포
- 맞으면 화면 가장자리가 붉게 번쩍이고, 체력 30% 아래에서는 숨 쉬듯 깜빡임
- 대시하면 내 몸 모양 잔상이 남음

## 파일 구성

```
arena-100/
├── arena-100.rbxlx                  스튜디오에서 바로 여는 게임 파일
├── default.project.json             Rojo 프로젝트 설정
└── src/
    ├── shared/
    │   ├── GameConfig.lua           수치와 데이터 (서버·클라이언트 공용)
    │   ├── GradeStyle.lua           등급 1~100마다 다른 색, 속성, 재질, 장식 (공용)
    │   ├── WeaponBuilder.lua        무기 모양(칼날 12종)과 장식, 강화 장식, 등급 오라 (공용)
    │   └── AuraBuilder.lua          상점 아우라 30종 (공용)
    ├── server/ArenaServer/
    │   ├── init.server.lua          전투, 웨이브, 필살기, 합성, 저장
    │   ├── WorldBuilder.lua         조명, 로비(용광로·전시대·훈련장), 투기장
    │   ├── EnemyBuilder.lua         적 12종의 생김새, 정예·초월 장식
    │   ├── EnemyAI.lua              적 종류별 행동, 보스 기술
    │   └── Skills.lua               무기 스킬 12종
    └── client/ArenaClient/
        ├── init.client.lua          화면 UI와 조작
        ├── Effects.lua              베기 궤적, 치명타, 스킬·필살기·적 공격 연출, 효과음
        ├── Motion.lua               관절 모션: 전투 자세, 3단 콤보, 구르기, 적 공격 동작
        └── KillFx.lua               킬 이펙트 30종, 아우라 파동, 사제 치유 연출
```

`src`를 고친 뒤 게임 파일을 다시 만들려면 [Rojo](https://rojo.space)로 `rojo build default.project.json -o arena-100.rbxlx`를 실행합니다.
