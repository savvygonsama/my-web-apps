# 업무 스타일 진단

직장인이 자기 업무 방식을 스스로 점검하고, 함께 일하는 사람과의 궁합을 확인하는 웹앱.
팀 워크숍과 신입 온보딩에서 쓰는 것을 전제로 만들었다.

## 파일

| 파일 | 내용 |
|---|---|
| `업무스타일진단.html` | 앱 본체. 브라우저로 열면 바로 실행된다. |
| `업무스타일_문항설계_v1.html` | 문항 40개 전문과 축별 이론 근거를 정리한 설계 문서. |

서버도 설치도 필요 없다. HTML 파일 하나에 전부 들어 있고, 답과 결과는 어디에도 저장·전송되지 않는다.

## 구조

**8축 40문항** (약 6분)

| 축 | 양쪽 끝 | 바탕이 된 연구 |
|---|---|---|
| 추진 템포 | 속도형 ↔ 완성도형 | 성실성(Big Five)의 신중성 요인 |
| 우선순위 | 과업 중심 ↔ 관계 중심 | 오하이오 리더십 2요인 |
| 의사결정 | 주도형 ↔ 조율형 | 주장성 연구, 참여적 의사결정 모형 |
| 시야 | 큰그림형 ↔ 디테일형 | 해석수준이론 |
| 변화 대응 | 검증 후 이동 ↔ 일단 시도 | 조절초점이론 |
| 피드백 방식 | 직설형 ↔ 완곡형 | 공손성 이론, 피드백 개입 메타분석 |
| 일 맡기고 받기 | 자율 선호 ↔ 절차 선호 | 자기결정이론, 직무특성모형 |
| 압박 상황 | 정면 돌파 ↔ 거리 두고 재정비 | 스트레스 대처 이론 |

앞의 네 축은 일하는 방식, 뒤의 네 축은 사람 사이에서 마찰이 생기는 지점이다.

**역할 분기** — 첫 화면에서 직책자와 팀원 중 하나를 고르면 문항 7개의 장면이 바뀐다.
팀원에게 성립하지 않는 상황("팀원이 실수했다", "일을 맡길 때")을 갈아끼우기 위한 것이고,
**축·방향·채점 방식은 양쪽이 완전히 동일하다.** 이게 지켜져야 두 사람을 같은 자로 잴 수 있다.

**결과** — 여덟 축 기울기 그래프, 강점·주의 카드, 약점별 실천 팁, 어울리는 일과 힘이 더 드는 일,
그리고 결과 코드.

**궁합** — 각자 진단을 마친 뒤 결과 코드를 주고받는다. 상대 코드와 관계(상사/동료/후배)를 넣으면
반대로 기운 축의 마찰과 대처법, 같은 쪽으로 기운 축의 공유 맹점을 보여준다.
같은 조합이라도 상대가 상사냐 후배냐에 따라 조언이 달라진다.

## 결과 코드

```
SL-L-AAAW-AAAA
   │ └──┬───┘
   │    └── 여덟 축 점수 (-10~+10을 21단계 문자로. 헷갈리는 I·O는 제외)
   └─────── 자리: L=직책자, T=팀원
```

## 설계 원칙

세 가지를 지켰다. 이걸 어기면 조직에서 못 쓰는 도구가 된다.

**1. 검사가 아니라 대화 도구다.** "당신은 ○○형"이라고 단정하지 않고 축마다 기울기를 보여준다.
성격 특성은 실제로 연속 분포이지 유형으로 딱 갈리지 않는다.

**2. 궁합은 판정이 아니라 처방이다.** "안 맞음" 대신 "이렇게 하면 통함"으로 쓴다.
닮은 조합도 "잘 맞음"으로 끝내지 않고 둘이 함께 놓칠 맹점을 반드시 같이 알려준다.

**3. 인사 평가에 쓰지 않는다.** 이 문항들은 학술적으로 타당화된 검사가 아니다.
위 이론들은 문항과 조언을 만드는 근거일 뿐이며, 앱 안에도 이 사실과 함께
채용·평가·배치의 근거로 쓰지 말라는 안내를 넣었다.

MBTI를 근거로 쓰지 않은 이유는 재검사 신뢰도가 낮고 사람을 이분법으로 나누기 때문이다.
뇌과학은 이 영역에서 실증적으로 말해줄 수 있는 게 거의 없어 근거에서 제외했다.
