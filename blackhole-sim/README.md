# 🕳 BLACK HOLE (블랙홀 시뮬레이터, 베타 2)

로블록스용 시뮬레이터 게임입니다. 내가 작은 블랙홀이 되어 돌아다니면, 내 크기보다 작은 건 전부 소용돌이치며 빨려 들어옵니다.
삼킨 만큼 질량이 쌓이고, 질량으로 몸집을 키워 돌멩이에서 시작해 자동차, 빌딩, 산, 마지막엔 행성과 태양까지 삼킵니다.

**베타 2에서 바뀐 것**

- 🍭 **세계 2 「과자 왕국」**: 첫 빅뱅을 하면 열립니다. 구역 5개, 과자 물체 22종, 질량은 세계 1의 약 5배
- 🌑 **빅뱅 상점**: 빅뱅하면 암흑 물질을 받고, 빅뱅해도 남는 업그레이드 7종을 삽니다
- 🛰 **위성(펫)**: 캡슐 3종에서 위성 18종이 나옵니다. 블랙홀 둘레를 돌며 질량 배율을 올려 줍니다. 같은 위성 5개를 합치면 황금 위성이 됩니다
- 🎨 **스킨 12종**: 불꽃, 얼음, 은하, 사탕, 황금, 신의 눈 효과
- 💎 **로벅스 상점**: VIP, 질량 2배, 속도 2배, 위성 칸 +2, 행운 부화, 3개 부화, **우주 위성 패키지(2199 로벅스)**, 부스트와 꾸러미
- ⚡ **더 빠른 진행**:
  - 크기는 레벨마다 13%씩 커집니다
  - 🤖 자동 업그레이드
  - ⭐ 별똥별: 삼키면 60초 동안 질량 2배
  - 빅뱅 조건이 레벨 38로 낮아졌습니다
- ♻ **재생산**: 삼킨 물체가 5~10초 만에 뿅 하고 다시 생깁니다. 빅뱅 상점, VIP, 부스트로 더 빨라집니다
- 🏠 **더 자세한 물체 모양**: 바퀴·휠캡·사이드미러, 창틀·현관 계단 같은 작은 부품까지 붙였습니다
- 📜 도움말과 설명 글씨를 크게 키웠습니다

## 바로 해 보기

### 방법 1. 게임 파일 열기 (가장 쉬움)

1. 이 폴더의 [`blackhole-sim.rbxlx`](blackhole-sim.rbxlx)를 엽니다
2. 오른쪽 위 **Download raw file** 버튼으로 내려받습니다
3. 내려받은 파일을 더블클릭하면 로블록스 스튜디오에서 열립니다
4. 위쪽 **Play** 버튼(▶)을 누르면 바로 시작됩니다

### 방법 2. 스크립트 직접 붙여 넣기

스튜디오에서 **Baseplate** 템플릿으로 새 게임을 만든 다음, 아래 여덟 개를 만들고 내용을 그대로 붙여 넣습니다.
"안에"라고 적힌 것은 그 스크립트를 오른쪽 클릭해서 그 아래에 만듭니다.

| 넣을 곳 (탐색기 창) | 만들 것 | 이름 | 붙여 넣을 파일 |
|---|---|---|---|
| ReplicatedStorage | ModuleScript | `Config` | [`src/shared/Config.lua`](src/shared/Config.lua) |
| ReplicatedStorage | ModuleScript | `Props` | [`src/shared/Props.lua`](src/shared/Props.lua) |
| ReplicatedStorage | ModuleScript | `SatBuilder` | [`src/shared/SatBuilder.lua`](src/shared/SatBuilder.lua) |
| ServerScriptService | Script | `HoleServer` | [`src/server/HoleServer/init.server.lua`](src/server/HoleServer/init.server.lua) |
| `HoleServer` 안에 | ModuleScript | `World` | [`src/server/HoleServer/World.lua`](src/server/HoleServer/World.lua) |
| `HoleServer` 안에 | ModuleScript | `Store` | [`src/server/HoleServer/Store.lua`](src/server/HoleServer/Store.lua) |

맵, 물체, 조명, 화면 UI는 스크립트가 알아서 만듭니다. Baseplate는 스크립트가 지우고 구역 바닥을 깝니다.
방법 2로 만들 때는 **Workspace → StreamingEnabled**를 꺼 주세요. 켜 두면 멀리 있는 물체가 들락날락하며 "다시 생기는" 연출이 엉뚱하게 나옵니다. 게임 파일(방법 1)은 이미 꺼져 있습니다.

### 🧪 테스트 계정

스튜디오에서 ▶ Play로 들어가거나, 게임을 올린 뒤 **게임 주인**으로 들어가면 테스트 계정이 됩니다.
왼쪽 **🧪 테스트** 창에서 다음을 쓸 수 있습니다.

- 질량 받기 (+1K ~ +1Qa)
- 크기 레벨 바로 정하기
- 모든 업그레이드 최대
- 암흑 물질 +50, 빅뱅 +1
- 별똥별 바로 떨어뜨리기
- 처음으로 되돌리기

테스트 계정은 상점 번호가 0인 게임패스·상품을 누르면 **무료로 산 것처럼** 처리되어 효과를 미리 볼 수 있습니다.
테스트 계정의 기록은 저장하지 않습니다. 정식 공개 전에는 [`Config.lua`](src/shared/Config.lua)의 `Config.TEST_MODE`를 `false`로 바꾸세요.

### 저장 기능 켜기

저장은 로블록스 서버(DataStore)를 씁니다. 스튜디오에서 저장까지 확인하려면 **File → Publish to Roblox**로 한 번 올린 뒤
**Home → Game Settings → Security**에서 **Enable Studio Access to API Services**를 켜세요.

## 💎 로벅스 상점 연결하기

상점에 보이는 상품은 [`Config.lua`](src/shared/Config.lua)의 `Config.GamePasses`(게임패스)와 `Config.Products`(개발자 상품)에 있습니다.
지금은 번호(`id`)가 모두 `0`입니다. 번호가 0이면 일반 플레이어에게는 "준비 중"이 뜨고, 테스트 계정에는 무료로 처리됩니다.

1. 게임을 **File → Publish to Roblox**로 올립니다
2. 웹사이트 **Creator Dashboard → 내 게임 → Monetization**으로 갑니다
3. **Passes**에서 게임패스 7개를 만듭니다
   - VIP, 질량 2배, 속도 2배, 위성 칸 +2, 행운 부화, 3개 부화, 우주 위성 패키지
   - 가격은 표의 권장 가격(우주 위성 패키지 2199)으로 정합니다
4. **Developer Products**에서 상품 5개를 만듭니다: 질량 2배 30분, 빠른 재생산 30분, 질량 꾸러미 소·대, 암흑 물질 10개
5. 만든 상품의 번호(ID)를 복사해 `Config.lua`의 같은 이름 줄 `id = 0` 자리에 넣습니다
6. `Config.TEST_MODE = false`로 바꾸고 다시 올립니다

## 🛰 위성 (펫)

🥚 캡슐 창에서 질량으로 캡슐을 깹니다. 나온 위성은 빈 칸이 있으면 바로 블랙홀 둘레를 돌기 시작합니다.

| 캡슐 | 값 | 위성 (배율) |
|---|---|---|
| 별빛 캡슐 | 💠1K | 돌멩이 위성 ×1.2, 꼬마 달 ×1.35, 혜성 ×1.7, UFO ×2.4, 꼬마 블랙홀 ×4, 황금 별 ×10 |
| 은하 캡슐 | 💠20M | 고리 행성 ×3, 탐사 로봇 ×4, 수정 소행성 ×6, 성운 해파리 ×10, 쌍성 ×20, 퀘이사 ×60 |
| 과자 캡슐 (세계 2) | 💠2B | 젤리 위성 ×20, 쿠키 행성 ×30, 사탕 혜성 ×50, 케이크 UFO ×90, 무지개 도넛 ×180, 과자의 신 ×500 |

- 장착한 위성 배율은 더해집니다: 위성 배율 = 1 + Σ(배율 − 1)
- 기본 3칸입니다. VIP +1, 위성 칸 +2, 우주 위성 패키지 +1, 빅뱅 상점 +2로 늘어납니다
- 같은 위성 5개 → ✨ 황금 위성 (효과 2.5배)
- 가방은 60칸이고, 비밀 위성은 버릴 수 없습니다

## 연출

- 블랙홀
  - 검은 구멍, 어두운 원반, 숨 쉬듯 빛나는 테두리
  - 도는 소용돌이 팔 세 개, 빠르게 도는 강착 원반, 안으로 빨려 드는 빛 알갱이
- 스킨 효과
  - 🔥 불꽃이 솟고, ❄ 얼음 조각과 눈이 돌고, 🌌 별빛 고리가 기울어 돕니다
  - 🍬 사탕 가루가 날리고, ✨ 금빛이 반짝입니다
  - 👁 눈동자가 움직이는 쪽을 바라봅니다
- 위성은 블랙홀 둘레를 둥실거리며 돌고, 황금 위성은 금박으로 반짝입니다
- 삼키기: 물체가 조각조각 소용돌이치며 작아져 구멍 속으로 사라지고, "+질량" 숫자가 떠오릅니다
- 재생산: 물체가 작게 나타났다가 통통 튀듯 원래 크기로 커집니다
- 별똥별은 하늘에서 떨어져 빛기둥을 세우고, 삼키면 거대한 금빛 고리가 퍼집니다
- 캡슐 깨기: 흔들리다 번쩍 하며 위성이 등급 색깔과 함께 나타납니다

```
├── blackhole-sim.rbxlx            스튜디오에서 바로 여는 게임 파일
├── default.project.json           Rojo 프로젝트 설정
└── src/
    ├── shared/
    │   ├── Config.lua             수치: 업그레이드, 세계·구역, 물체 59종, 위성, 스킨, 빅뱅 상점, 로벅스 상점
    │   ├── Props.lua              물체 59종의 모양
    │   └── SatBuilder.lua         위성 18종의 모양
    ├── server/HoleServer/
    │   ├── init.server.lua        삼키기, 질량, 업그레이드, 빅뱅, 위성, 스킨, 부스트, 별똥별, 저장
    │   ├── World.lua              조명, 세계 2개의 구역과 문, 세계 문, 물체 배치
    │   └── Store.lua              게임패스와 개발자 상품 결제
    └── client/HoleClient/
        ├── init.client.lua        화면 UI(상점·캡슐·위성·스킨·빅뱅 상점·세계), 카메라, 문 통과
        └── Fx.lua                 블랙홀과 스킨 효과, 위성 궤도, 빨려 드는 연출, 재생산, 별똥별, 효과음
```

밸런스는 [`Config.lua`](src/shared/Config.lua) 한 파일에 있습니다.
`src`를 고친 뒤 게임 파일을 다시 만들려면 [Rojo](https://rojo.space)로 `rojo build default.project.json -o blackhole-sim.rbxlx`를 실행합니다.
