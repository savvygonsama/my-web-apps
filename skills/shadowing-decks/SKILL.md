# 쉐도잉 회차 만들기

곤사마(@POSCO)가 만든 쉐도잉 학습 앱 **두 개**를 다룬다. 엔진이 같아서 흐름도 같다.

| | 茶馆 CHÁGUǍN 🍵 | ROUNDTABLE 🎙 |
|---|---|---|
| 언어 | 중국어 | 영어 |
| 수준 | HSK 5~6 | B2 (토익스피킹 6~7급) |
| 성격 | 성인의 **일상 회화** — 사교·부탁·거절·하소연·협상 | 한 주제를 놓고 벌이는 **토론** |
| 한 줄 | 한자 15~28자 | 10~18단어 |
| id 접두 | `c` (c2d1) | `w` (w2d1) |
| 특징 | 병음(`py`)과 끊어읽기(`ck`)가 필수 | 병음·끊어읽기 없음 |
| 명세 | `references/schema-zh.md` | `references/schema-en.md` |
| 검증 | `node scripts/check_deck.js --zh 파일` | `node scripts/check_deck.js --en 파일` |

**어느 앱인지 먼저 확정하라.** 형식이 달라서 잘못 만들면 통째로 다시 써야 한다.

## 이 앱들의 좋은 점 — 아티팩트를 안 건드려도 된다

두 앱 모두 **"새 회화 추가"** 화면을 가지고 있다. JSON을 붙여넣고 버튼을 누르면
브라우저에 저장되어 커리큘럼 맨 뒤에 붙는다. 그래서 작업이 이렇게 끝난다.

1. 이 스킬대로 JSON을 만든다
2. 검증기를 돌린다
3. `.json` 파일로 사용자에게 보낸다
4. 사용자가 앱의 **새 회화 추가 → 2단계 붙여넣기 칸**에 붙여넣고 "회차 추가"를 누른다

아티팩트를 열 필요도, 백업할 필요도 없다. 앱이 깨질 위험도 없다.
JSON이 잘못되면 앱이 그냥 "형식이 맞지 않습니다"라고 알려 주고 아무 일도 일어나지 않는다.

**단, 저장 위치는 그 브라우저 하나다.** 추가한 회차는 다른 기기에서는 보이지 않는다.
사용자가 여러 기기에서 쓰고 싶어 하면 각 기기에서 같은 JSON을 붙여넣으면 되니,
파일을 잘 보관하라고 알려 준다.

## 앱 안에 이미 프롬프트가 들어 있다

두 앱 모두 화면에 **생성 프롬프트**를 품고 있고, 사용자가 그걸 복사해 쓰도록 만들어져 있다.
이 스킬은 그 프롬프트를 대체하는 것이 아니라 **그 위에 얹는 것**이다.
사용자가 만든 기준(문장 길이, 난이도, 반드시 넣을 문법)은 그대로 지키고,
여기서는 그 프롬프트가 다루지 않는 것을 더한다 — 형식 검증, 기존 회차와의 중복 확인, 파일로 전달.

명세 파일에 그 기준을 그대로 옮겨 두었다. **원고를 쓰기 전에 반드시 읽어라.**

## 작업 순서

1. **어느 앱인지, 몇 일차인지 확정.** `day`와 `id`는 기존 회차 다음 번호로 이어 간다.
   기본 내장 회차는 茶馆이 7일차까지, ROUNDTABLE이 그 앱 기준으로 있으니,
   사용자에게 지금 몇 일차까지 있는지 물어보고 시작하는 편이 안전하다.
2. **소재 정하기.** 사용자가 장면이나 주제를 정한다. 기존 회차와 겹치지 않는지 확인한다.
3. **원고 쓰기.** 해당 명세 파일대로. 20줄 대화가 뼈대다.
4. **검증.** `scripts/check_deck.js`를 돌린다. 통과할 때까지 고친다.
5. **전달.** `.json` 파일로 저장해 보내고, 붙여넣는 자리를 한 줄로 알려 준다.

## 공통 규칙

- **출력은 JSON 배열 하나.** 대괄호 `[ ... ]`로 시작하고 끝난다. 설명 문장을 앞뒤에 붙이지 않는다.
  앱이 `JSON.parse`로 통째로 읽기 때문에, 군더더기가 한 글자라도 있으면 거부한다.
- `id`는 겹치면 안 된다. 겹치면 앱이 임의 문자를 덧붙여 바꿔 버린다(사라지진 않지만 지저분해진다).
- **지어낸 통계·날짜·인용을 쓰지 않는다.** 두 앱의 프롬프트 모두 이걸 명시하고 있고,
  사용자가 특히 싫어하는 부분이다. 속보성 사실 대신 **오래 유효한 구조와 메커니즘**을 다룬다.
- `brief`는 한국어 배경설명 4문단. 대화를 듣기 전에 읽는 부분이라,
  **그 장면에서 무엇이 걸려 있는지**를 알려 준다. 단어 나열이 아니다.
- `notes`는 뜻만 적는 자리가 아니다. **비슷한 말과의 차이, 언제 쓰면 실례가 되는지, 확장형**을 적는다.
  이 앱들의 값어치가 여기에 있다.
- `out`은 배운 표현을 직접 말해 보게 하는 과제다. `hint`에 써야 할 표현을 적어 준다.

## 검증

```bash
node scripts/check_deck.js --zh deck-c2d1.json
node scripts/check_deck.js --en deck-w2d1.json
```

JSON 문법, 필수 필드, A/B 교대, 줄 수와 길이, `notes`의 분류값을 본다.
중국어는 여기에 더해 **끊어읽기(`ck`)를 이었을 때 원문과 같은지**, **병음 음절 수가 한자 수와 맞는지**까지 본다.
이 둘이 이 앱에서 가장 자주 깨지는 곳이다.

스크립트가 못 잡는 것 — 번역이 맞는지, 그 표현을 실제로 그렇게 쓰는지 — 은 읽어서 확인한다.

## 사용자에 대해

사용자는 본인을 "컴맹"이라고 말한다. 기술 용어를 앞세우지 말고, 붙여넣는 자리를 단계별로 알려 준다.
결과물은 항상 파일로 만들어 보낸다.
