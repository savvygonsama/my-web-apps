# ハングリンゴ Lite 회차 데이터 형식

앱 안의 `const DATA = [ ... ]` 배열에 들어가는 객체 하나의 명세다.
아래 예문은 실제 1과(큰비)에서 그대로 가져온 것이다. 형식이 헷갈리면 이 모양을 따라가면 된다.

**필드 이름을 스틸링고와 뒤집어 읽어라.** `ko`가 배우는 말(한국어), `ja`가 뜻(일본어)이다.

## 최상위 필드

```js
{
  no: 6,                              // 회차 번호. 앞 회차 + 1
  title: "큰비[クンビ]",               // 한국어 제목. 가타카나 루비 포함
  titleJa: "大雨",                     // 일본어 제목
  story: {...}, words: [...], sentences: [...],
  dialogue: {...}, quiz: [...], column: {...}
}
```

여섯 덩어리가 학습 순서 그대로다. 뉴스를 읽고 → 단어를 익히고 → 예문으로 문법을 보고 →
대화로 써 보고 → 퀴즈로 확인하고 → 칼럼으로 문화를 한 조각 얹는다.

## story — 뉴스 조각

```js
story: {
  topic: "災害・天気のニュース",          // 일본어로 적는다
  lines: [
    { ko: "어제[オジェ] 한국[ハングク] 남쪽[ナムッチョク]에[エ] 《비[ピ]》가[ガ] 《많이[マニ]》 왔습니다[ワッスムニダ].",
      ja: "昨日、韓国の南のほうで雨がたくさん降りました。" },
    // ... 모두 4줄
  ]
}
```

- `lines`는 **4줄**. 짧은 생활 뉴스 한 편을 4문장으로 줄인 분량이다.
- 그날 단어가 나오는 자리는 `《》`로 감싼다. 활용형이어도 감싼다(`《왔습니다[ワッスムニダ]》`).
- 이 4줄이 회차의 뼈대다. **story를 먼저 쓰고 거기서 단어 6개를 뽑아라.**
- 지문은 실제 기사가 아니라 학습용으로 새로 쓴 글이다. 앱 화면에도 그렇게 밝혀 둔다.

## words — 오늘의 단어 6개

```js
words: [
  { ko: "오다", disp: "오다[オダ]", kana: "オダ", mean: "来る、(雨・雪が)降る",
    note: "韓国語では雨は「降る」ではなく「来る」と言います。「비가[ピガ] 와요[ワヨ](雨が降ります)」が…" },
  // ... 모두 6개
]
```

| 필드 | 내용 | 주의 |
|---|---|---|
| `ko` | 사전형 순수 표기 | **대괄호도 《》도 넣지 않는다.** `sentences[i].for`와 글자 그대로 같아야 한다 |
| `disp` | 화면에 띄울 루비 표기 | `오다[オダ]`. 대괄호를 걷어내면 `ko`와 같아야 한다 |
| `kana` | 통째로 읽은 가타카나 | `disp`의 루비를 이어 붙인 것과 같으면 화면에 안 나온다. 달라질 때만 값어치가 있다 |
| `mean` | 일본어 뜻 | 짧게 |
| `note` | 한 문단 설명 | 일본어로. 짝이 되는 말, 헷갈리는 말, 쓰는 자리를 알려 준다 |

`note`가 이 앱의 값어치다. 뜻만 적지 말고 **어떤 말과 붙어 다니는지**를 알려 줘라.
「비가 오다」처럼 짝으로 외우게 하는 것이 낱말 하나를 외우는 것보다 오래 남는다.
일본어와 어긋나는 자리(「버스를 타다」의 `를`)는 **어긋난다고 못을 박아 준다.**

## sentences — 단어마다 예문 1개

`words`와 **1:1, 같은 순서**로 6개.

```js
{
  for: "오다",                                    // words[i].ko 와 완전히 같아야 함
  ko: "오늘[オヌル]은[ウン] 《비[ピ]》가[ガ] 《옵니다[オムニダ]》.",
  ja: "今日は雨が降ります。",
  frame: "A 은/는  B 이/가  ~ㅂ니다",              // 문형 뼈대. 기호와 공백으로 보여 준다
  parts: [
    { p: "오늘[オヌル]은[ウン]", r: "オヌルン", w: "今日は",
      why: "「은/는」は「これについて話します」と話題を立てる印です。パッチムがあれば「은」、なければ「는」。" },
    { p: "《비[ピ]》가[ガ]", r: "ピガ", w: "雨が", why: "その場の主人公を指す印です。" },
    { p: "《옵니다[オムニダ]》.", r: "オムニダ", w: "降ります", why: "「오다」の語幹「오」に「ㅂ니다」がついた形です。" }
  ],
  why: [
    "韓国語の入り口でいちばんつまずくのが <b>은/는</b> と <b>이/가</b> です。…",
    "だから「오늘<b>이</b> 비가 옵니다」とは言いません。…",
    "天気のように人の思いどおりにならないことは「이/가」とよく結びつきます。…"
  ],
  swap: { ko: "내일[ネイル]은[ウン] 눈[ヌン]이[イ] 옵니다[オムニダ].", ja: "明日は雪が降ります。" }
}
```

- **`parts`의 `p`를 띄어쓰기 한 칸으로 이어 붙이면 `ko`와 한 글자도 달라선 안 된다.**
  한국어는 낱말 사이를 띄우므로 일본어판처럼 그냥 붙이면 문장이 어긋난다.
  구두점은 `p` 안에 포함시킨다. 검증 스크립트가 가장 자주 잡아내는 오류다.
- `p` 하나는 **띄어쓰기 한 덩어리(어절)**다. 두 어절을 한 조각에 넣지 않는다.
- `r`은 그 조각을 **이어 읽었을 때의 가타카나**다. 루비를 이어 붙인 것과 달라도 된다 —
  오히려 다른 것이 값어치다(`한국[ハングク]에서는[エソヌン]` → `r: "ハングゲソヌン"`).
  학습자가 연음을 눈으로 확인하는 유일한 자리다.
- `w`는 일본어 뜻, `why`는 한 문장짜리 이유다(일본어).
- `why`(문장 단위, 바깥쪽)는 **3개**. 문법 규칙 하나를 세 각도에서 짚는다:
  규칙 → 그래서 이렇게는 안 쓴다 → 같은 모양의 다른 예.
- `swap`은 같은 문형에 낱말만 바꾼 문장이다. 문형이 재사용된다는 걸 몸으로 알게 하는 장치다.

## dialogue — 짧은 대화 6턴

```js
dialogue: {
  situation: "雨がひどく降る朝、マンションの入り口で隣の人と会いました。",   // 일본어
  turns: [
    { me: false,                                 // false = 상대, true = 나. 번갈아 나온다
      ko: "안녕하세요[アンニョンハセヨ]. 오늘[オヌル]은[ウン] 《비[ピ]》가[ガ] 《많이[マニ]》 오네요[オネヨ].",
      ja: "こんにちは。今日は雨がたくさん降りますね。",
      tip: "「~네요」はいまその場で気づいたことに言う語尾です。…",
      parts: [ { p: "...", r: "...", w: "...", why: "..." } ]   // sentences의 parts와 같은 형식
    },
    // ... 모두 6턴, false로 시작해 true로 끝난다
  ]
}
```

- **0번은 상대(false)로 시작해 번갈아 간다.** 마지막 5번은 나(true)로 끝난다.
- **내 대사(`me: true`)는 `parts`가 2개 이상**이어야 조각 맞추기 화면이 열린다.
  조각이 하나뿐이면 문제가 되지 않으므로 스크립트가 잡는다.
- 그날 배운 단어와 문형이 대화 안에서 다시 나오게 짠다.
- `tip`은 그 턴에서 눈여겨볼 한 가지(일본어). 인사 예절, 맞장구, 생략된 말 같은 것.
- 마지막 턴은 대화를 닫는 인사로 끝낸다.

## quiz — 8문항

```js
quiz: [
  { q: "「비[ピ](雨)」と組になる動詞はどれですか。",
    opts: ["쓰다[ッスダ]", "오다[オダ]", "불다[プルダ]"],
    ans: 1,                                      // 0부터 세는 번호
    msg: "雨は「오다」と組みます。「비가 와요」でまるごと覚えてください。" }
  // ... 모두 8문항
]
```

- `opts`는 **항상 3개**. `ans`는 `0`~`2`. 질문·보기·해설 모두 일본어로 묻되, 한국어는 루비를 붙인다.
- 그날 다룬 것만 묻는다. 오답 보기도 그날 나온 말에서 고르면 복습이 한 번 더 된다.
- **정답 자리를 한쪽에 몰지 않는다.** 스크립트가 회차 안의 쏠림을 잡는다(최대차 3).
- **가장 긴 보기가 정답이 되지 않게 한다.** 뜻을 몰라도 큰 덩어리를 누르면 맞는 문항이 된다.
  이것도 스크립트가 잡는다. 오답을 같은 길이의 **실제로 쓰이는 표현**으로 채워라.
- **없는 말로 만든 보기는 문항당 하나까지.** 「맵어요」처럼 존재하지 않는 활용형에 루비가
  정상적으로 붙으면 진짜 낱말로 보인다. 나머지 오답 하나는 이미 배운 진짜 말로 둔다.
- **질문과 보기에 문법 용어를 쓰지 않는다.** 「해요체に活用すると」이 아니라 「해요체にすると」다.
- **기존 문항과 겹치지 않는지 반드시 대조한다.** 정답 문장이 같으면 그것은 새 문항이 아니다.

### 여덟 문항의 짜임

| 자리 | 하는 일 |
|---|---|
| 1~4번 | 그날 배운 것을 그대로 확인한다. 회차가 올라가도 이 넷은 늘 쉽게 유지한다 |
| 5번 | 그날 단어 하나의 뜻. 어느 회차에서나 가장 쉬운 문항이다 |
| 6~8번 | 회차 묶음의 단계에 맞춰 한 걸음씩 깊어진다 (아래) |

### 5회차 묶음마다 오르는 단계

앱의 `QUIZ_WAYS`와 같은 순서다. 화면에서는 **5번 문항 바로 앞**에 얇은 구분선과 함께
「ここから — ことばと相棒」 같은 회색 알약으로 표시된다. **「難易度」나 「N段階」라는 말은 화면에 쓰지 않는다.**

| 회차 | 단계 | 6~8번이 묻는 방식 |
|---|---|---|
| 1~5 | ことばと相棒 | 뜻, 어울리는 말, 기본 활용 |
| 6~10 | かたちを変える | 배운 말을 그날 문형에 맞게 바꾸기 |
| 11~15 | 穴うめ | 문장 속 조사와 어미 고르기 |
| 16~20 | 場面に合うことば | 상황을 주고 알맞은 표현 고르기 |
| 21~25 | 正しい文を選ぶ | 비슷한 문장 셋 중 바른 것 |
| 26~30 | 言外の意味 | 뉘앙스와 업무에서의 실제 의미 |

**여기서 올라가는 것은 묻는 방식뿐이다. 새로운 문법 지식을 더하지 않는다.**
이 선을 지켜야 회차를 건너뛴 사람도 그날 본문만 읽으면 풀 수 있다.

## column — 마무리 칼럼

```js
column: {
  word: "장마[チャンマ]", kana: "チャンマ", ja: "梅雨",
  title: "日本の梅雨、韓国の장마[チャンマ] — 同じ季節、違う顔",
  body: [ "段落 1 ...", "段落 2 ...", "段落 3 ..." ],
  note: "「장마[チャンマ]」は名詞です。「장마가[チャンマガ] 오다[オダ](梅雨が来る)」のように使います。"
}
```

- 그 회차 주제와 이어지는 **말 한 개**를 골라, 그 말이 한국 사회에서 어떻게 쓰이는지를 이야기한다.
- `body`는 3문단(일본어). 마지막 문단은 가능하면 **업무 장면**으로 내린다
  (거래처, 메일, 회식, 경조사). 읽는 사람이 한국과 일로 엮여 있기 때문이다.
- 칼럼 안에서 인용하는 한국어에도 **루비를 붙인다.** 읽을 수 없는 글자를 던져 놓지 않는다.
- `note`는 형태상 주의 한 줄.

## 음성 키 계산

앱은 문장을 읽어 줄 때 `AUDIO_DATA[key]`를 먼저 찾고, 없으면 브라우저 음성으로 간다.
지금은 `AUDIO_DATA`가 비어 있으므로 항상 브라우저 음성이다. 나중에 녹음을 넣을 때 쓸 키는 이렇게 만든다.

1. 표시용 표기를 **읽기용 텍스트**로 바꾼다: `{표기}[한글읽기/カナ]` → 한글읽기,
   `한글[カナ]` → 한글, `《》` → 제거.
2. UTF-8 바이트에 FNV-1a 32비트 해시를 돌린다.
3. 16진수 8자리(앞을 0으로 채움)가 키다.

```js
function keyOf(t) {
  const b = new TextEncoder().encode(t);
  let h = 0x811c9dc5;
  for (const x of b) { h ^= x; h = Math.imul(h, 0x01000193) >>> 0; }
  return h.toString(16).padStart(8, "0");
}
```

키가 없으면 브라우저 내장 음성으로 물러난다.
**그래서 새 회차를 넣어도 앱은 멈추지 않는다.**
