# 상담·메일 실무 표현과 일본식 완곡어법

용어를 알아도 이 부분에서 무너지면 상담이 어긋난다. 일본 비즈니스 일본어는 **무엇을 말하느냐보다 어떻게 말하느냐**가 관계를 좌우한다.

> **한글 발음 표기는 이 파일 안에서만 쓰는 내부 참고 정보다. 학습 자료에는 절대 옮기지 않는다.** 자료에 싣는 읽기는 요미가나(가나)뿐이다.

## 1. 대화의 뼈대가 되는 표현

거의 모든 상담이 이 표현들 위에서 굴러간다. 여덟 개만 입에 붙어도 회의가 달라진다.

| 표현 | 읽기 | 뜻 / 쓰는 자리 |
|---|---|---|
| お世話(せわ)になっております | 오세와니 낫테오리마스 | 첫인사. 전화·메일·대면 어디서든 첫마디. 뜻을 따지지 말고 통째로 외운다 |
| 早速(さっそく)ですが | 삿소쿠데스가 | "바로 본론입니다만" — 인사 후 본론 진입 신호 |
| 承知(しょうち)いたしました | 쇼-치 이타시마시타 | "알겠습니다" 의 가장 안전한 형태. 「了解です」는 윗사람·고객에게 부적절 |
| かしこまりました | 카시코마리마시타 | 承知보다 더 공손. 의뢰를 받을 때 |
| 恐(おそ)れ入(い)りますが | 오소레이리마스가 | "송구합니다만" — 부탁·반론 앞에 쿠션처럼 깐다 |
| お手数(てすう)をおかけしますが | 오테스-오 오카케시마스가 | "번거로우시겠지만" — 상대에게 일을 시킬 때 |
| ご検討(けんとう)のほど、よろしくお願(ねが)いいたします | 고켄토-노 호도, 요로시쿠 오네가이 이타시마스 | 제안·견적을 넘기며 맺는 말 |
| 引(ひ)き続(つづ)きよろしくお願(ねが)いいたします | 히키츠즈키 요로시쿠 오네가이 이타시마스 | 마무리 인사. 메일 끝에 거의 자동 |

### 쿠션 표현 (クッション言葉)

거절·부탁·반론 앞에 붙여 충격을 줄인다. 이걸 빼면 같은 내용이라도 무례하게 들린다.

- 恐(おそ)れ入(い)りますが — 송구합니다만
- 申(もう)し訳(わけ)ございませんが — 죄송합니다만
- 大変(たいへん)恐縮(きょうしゅく)ですが — 대단히 송구합니다만
- あいにくですが — 공교롭게도
- ご相談(そうだん)なのですが — 상의드릴 게 있습니다만 (부탁을 부드럽게 꺼낼 때)

## 2. 완곡어법 — 진짜 뜻 읽기

**일본 상담에서 "안 된다"는 말은 거의 나오지 않는다.** 거절은 아래 형태로 온다. 이걸 긍정으로 오독하면 될 거라 믿고 보고를 올렸다가 뒤집힌다.

| 상대가 하는 말 | 표면적 뜻 | 실제 의미 |
|---|---|---|
| 検討(けんとう)させていただきます | 검토하겠습니다 | 대개 보류 또는 완곡한 거절. 진짜 검토일 때도 있으나 기대치를 낮춰야 함 |
| 難(むずか)しいですね | 어렵네요 | 사실상 불가. "어렵지만 가능"이 아니다 |
| ちょっと厳(きび)しいです | 좀 빠듯합니다 | 거절 |
| 前向(まえむ)きに検討(けんとう)します | 긍정적으로 검토하겠습니다 | 「検討します」보다는 낫지만 확약 아님 |
| 社内(しゃない)で確認(かくにん)します | 사내 확인하겠습니다 | 즉답 회피. 다만 실제로 결재 구조상 필요한 경우도 많음 |
| 持(も)ち帰(かえ)ります | 가지고 돌아가겠습니다 | 그 자리에서 결정하지 않겠다는 뜻 |
| 善処(ぜんしょ)します | 선처하겠습니다 | 거의 아무 약속도 하지 않은 것 |
| 結構(けっこう)です | 좋습니다 / 됐습니다 | **승낙과 거절 양쪽**. 앞뒤 문맥과 표정으로 판단. 애매하면 되물어야 함 |

**되묻는 법** — 애매할 때 확인하는 표현. 무례하지 않게 확답을 유도한다.

```
念(ねん)のため確認(かくにん)させていただきたいのですが、
ネンノタメ 카쿠닌사세테 이타다키타이노데스가,
"확인 차 여쭙습니다만,"

〜という理解(りかい)でよろしいでしょうか。
〜토 유- 리카이데 요로시-데쇼-카.
"〜라는 이해로 괜찮을까요?"
```

**우리 쪽이 거절할 때**도 같은 어법을 쓴다. 「できません」은 너무 직설적이다.

```
社内(しゃない)で検討(けんとう)いたしましたが、今回(こんかい)は難(むずか)しい状況(じょうきょう)でございます。
대신 가능한 대안을 반드시 붙인다:
ただ、〜であれば対応(たいおう)可能(かのう)かと存(ぞん)じます。
"다만, 〜라면 대응 가능할 것으로 생각합니다."
```

## 3. 상황별 표현

### 가격 협상

| 표현 | 뜻 |
|---|---|
| 原料価格(げんりょうかかく)の高騰(こうとう)を受(う)けまして | 원료 가격 급등에 따라 |
| コスト上昇分(じょうしょうぶん)を転嫁(てんか)させていただきたく | 원가 상승분을 반영하고자 |
| ご理解(りかい)いただけますと幸(さいわ)いです | 이해해 주시면 감사하겠습니다 |
| 何(なん)とかご検討(けんとう)いただけないでしょうか | 어떻게든 검토해 주실 수 없을까요 |
| 据(す)え置(お)きでお願(ねが)いできませんか | 동결로 부탁드릴 수 없을까요 |

### 납기 조정

| 표현 | 뜻 |
|---|---|
| 納期(のうき)を前倒(まえだお)しできますでしょうか | 납기를 앞당길 수 있을까요 |
| 分納(ぶんのう)という形(かたち)ではいかがでしょうか | 분할 납품 형태는 어떠신지요 |
| 〜までには手配(てはい)いたします | 〜까지는 준비하겠습니다 |
| 状況(じょうきょう)を確認(かくにん)のうえ、ご連絡(れんらく)いたします | 상황 확인 후 연락드리겠습니다 |

### 클레임 대응 — 사과의 3단계

일본에서 사과는 정도가 명확히 나뉜다. 사안 크기에 맞춰야 한다. 가벼운 일에 최상급을 쓰면 과하고, 무거운 일에 가벼운 표현을 쓰면 성의 없어 보인다.

| 단계 | 표현 | 쓰는 자리 |
|---|---|---|
| 가벼움 | 申(もう)し訳(わけ)ありません | 사소한 착오 |
| 표준 | 申(もう)し訳(わけ)ございません | 업무상 대부분 |
| 최상급 | ご迷惑(めいわく)をおかけし、誠(まこと)に申(もう)し訳(わけ)ございません | 품질 사고, 납기 펑크 |

사과 후 반드시 이어지는 흐름이 있다. 이 순서를 지키지 않으면 성의를 의심받는다.

```
1. 사과      ご迷惑をおかけし、誠に申し訳ございません。
2. 사실 확인  現在(げんざい)、原因(げんいん)を究明(きゅうめい)しております。
3. 잠정 대책  取(と)り急(いそ)ぎ、代替品(だいたいひん)を手配(てはい)いたしました。
4. 항구 대책  再発防止策(さいはつぼうしさく)をまとめ、来週(らいしゅう)ご報告(ほうこく)いたします。
```

## 4. 메일 정형 구조

일본 비즈니스 메일은 형식이 굳어 있다. 이 틀을 벗어나면 내용이 좋아도 이상하게 읽힌다.

```
株式会社〇〇
調達部　〇〇様

いつも大変お世話になっております。
POSCOの〇〇でございます。

早速ですが、〇月〇日にご依頼いただきました件につきまして、
ご連絡差し上げます。

（본문）

ご不明な点がございましたら、お気軽にお申し付けください。
引き続きよろしくお願いいたします。

――――――――――
POSCO　輸出チーム
〇〇　〇〇
```

**핵심 규칙**
- 수신자는 「会社名 → 部署名 → 個人名＋様」 순
- 「様(さま)」는 개인에게, 「御中(おんちゅう)」는 조직에게. 둘을 같이 쓰지 않는다
- 첫 줄은 반드시 「いつもお世話になっております」
- 용건은 두괄식으로 — 무슨 건인지 먼저 밝히고 상세를 뒤에 둔다
- 자기 회사에는 「弊社(へいしゃ)」, 상대 회사에는 글에서 「貴社(きしゃ)」, 말에서 「御社(おんしゃ)」

## 5. 한국인이 자주 하는 실수

| 실수 | 왜 문제인가 | 대신 |
|---|---|---|
| 了解(りょうかい)です | 동료·아랫사람용. 고객에게 쓰면 건방지게 들림 | 承知いたしました |
| ご苦労様(くろうさま)です | 윗사람이 아랫사람에게 쓰는 말 | お疲(つか)れ様(さま)です |
| 「はい」만 반복 | 듣고 있다는 표시일 뿐 동의로 읽히지 않음. 반대로 상대의 「はい」도 동의가 아님 | 확답이 필요하면 되물어 확인 |
| 자기 회사 사람에게 존칭 | 고객 앞에서 「部長様がおっしゃいました」는 결례. 사내 인물은 낮춤 | 「部長の〇〇が申しておりました」 |
| 즉답으로 확약 | 일본 측은 즉답을 신중함 부족으로 볼 수 있음 | 社内で確認のうえ、改めてご連絡いたします |
| 「大丈夫です」 남용 | 승낙·거절 양쪽으로 읽혀 오해를 부름 | 문제없음 → 問題(もんだい)ございません / 사양 → 結構(けっこう)でございます |

### 헷갈리는 한자어

한자가 같아 보여 방심하는 곳에서 사고가 난다.

| 일본어 | 실제 뜻 | 한국어 감각으로 오해하기 쉬운 뜻 |
|---|---|---|
| 手紙(てがみ) | 편지 | 화장지 |
| 汽車(きしゃ) | 증기기관차 | 자동차 (자동차는 車·自動車) |
| 工場(こうじょう) | 공장 | — 단, 「工場(こうば)」로 읽으면 소규모 작업장 |
| 都合(つごう) | 사정, 형편 | 「都合が悪い」는 "사정이 안 좋다"= 곤란하다 |
| 検討(けんとう) | 검토 | 실제로는 보류·거절 신호인 경우가 많음 |
| 遠慮(えんりょ) | 사양, 삼감 | 「ご遠慮ください」는 "삼가 주세요"= 금지 |
| 出来(でき)ます | 가능합니다 | — 「出来かねます」는 "불가능합니다"의 완곡형 |
