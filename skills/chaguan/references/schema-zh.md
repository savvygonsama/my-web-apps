# 茶馆 CHÁGUǍN — 중국어 쉐도잉 회차 형식

앱의 "새 회화 추가" 화면에 붙여넣는 JSON 배열 하나의 명세다.
아래 예시는 실제 1일차(饭局 — 술자리)에서 가져왔다.

## 학습자와 목표 (앱에 적힌 기준 그대로)

- 한국인 직장인. 중국어 말하기는 중상급(HSK 5~6). 기본 회화는 되지만 **어른스러운 구어와 관용 표현**이 부족하다.
- 목표는 시사·비즈니스 용어가 아니라 **성인의 일상 회화**.
  사교·부탁·거절·하소연·협상처럼 실제 관계 속에서 오가는 말을 늘리는 것.

## 반드시 지킬 조건

- 두 사람(A/B)이 한 장면에서 나누는 자연스러운 대화 **20줄**, A/B 번갈아.
- 한 줄은 **한자 15~28자**. 짧은 초급 문장을 쓰지 않는다.
- 어휘는 HSK 5~6 중심. 회차마다 **성어·관용어 2~4개**, 구어체 표현(别提了 / 可不是嘛 / 要我说 등)을 넉넉히.
- 반드시 넣을 **구어 골격**: 가능보어(V得住 / V不了 / 推不掉), 把자문, 连…都…, A是A可是…,
  A归A, 越…越…, 能…则…, 非得…才…, 总不能…吧, 说是这么说.
- 지어낸 통계·인용 금지. 일상 장면의 사실적인 대화만.

## 전체 모양

```json
[{
  "id": "c2d1", "day": 8, "cat": "장면분류", "level": "HSK 5~6",
  "title": "中文标题", "titlePy": "zhōngwén biāotí", "titleKo": "한국어 제목 — 부제",
  "names": { "A": "이름 (역할)", "B": "이름 (역할)" },
  "brief": ["배경설명 1", "2", "3", "4"],
  "vocab": [ { "w": "单词", "p": "dāncí", "m": "뜻", "lv": "HSK5" } ],
  "lines": [ … 20줄 … ],
  "keys": [ … 핵심 표현 … ],
  "out":  [ … 말하기 과제 … ]
}]
```

`id`는 `c` + 묶음번호 + `d` + 일차. 2번째 묶음의 첫 회차면 `c2d1`.
`cat`은 장면 분류 — 회식·술자리 / 쇼핑·분쟁 / 교통·응대 / 하소연·위로 / 부탁·인간관계 / 클레임·협상 등.

`titleKo`는 `"환불 협상 — 안 된다는 답을 뒤집기"`처럼 **제목 — 부제** 형태로 쓴다.
부제가 그 회차에서 배우는 기술을 한마디로 말해 준다.

## vocab — 오늘의 단어

```json
{ "w": "见外", "p": "jiànwài", "m": "남처럼 굴다, 서먹하게 대하다", "lv": "HSK6" }
```

- 10~12개. `lv`은 `"HSK5"`, `"HSK6"`, `"성어"`, `"구어"` 중 하나.
- 대화에 실제로 나온 말만 넣는다.

## lines — 대화 20줄

```json
{
  "s": "B",
  "zh": "来来来，别客气，今天这顿说什么也得我来。",
  "py": "Lái lái lái, bié kèqi, jīntiān zhè dùn shuō shénme yě děi wǒ lái.",
  "ko": "자자, 사양 마세요, 오늘 이 자리는 무슨 일이 있어도 제가 냅니다.",
  "ck": [ ["来来来，别客气", "lái lái lái, bié kèqi"],
          ["今天这顿", "jīntiān zhè dùn"],
          ["说什么也得我来", "shuō shénme yě děi wǒ lái"] ],
  "notes": [
    { "t": "说什么也得…", "p": "shuō shénme yě děi…", "k": "expr",
      "m": "무슨 일이 있어도 ~해야 한다",
      "tip": "무조건이라는 뜻의 구어 골격입니다. 说什么也不能答应 = 절대 승낙할 수 없다." },
    { "t": "顿", "p": "dùn", "k": "measure", "m": "끼니를 세는 양사",
      "tip": "一顿饭 / 三顿 / 请你吃顿饭. 식사에는 次가 아니라 顿을 씁니다." }
  ]
}
```

### py — 병음

- **성조 부호를 정확히** 넣는다.
- **一/不 성조 변화를 반영한다** — `yí ge`, `yìdiǎnr`, `búcuò`.
- **儿化는 붙여 쓴다** — `diǎnr`, `xìnr`, `yōu zhe diǎnr`.
- 음절 수가 한자 수와 일치해야 한다(儿화 제외). 검증기가 센다.
- 문장 첫 글자만 대문자. 고유명사는 대문자(`Lǎo Zhōu`, `Shǒu'ěr`).

### ck — 끊어읽기

- 한 줄을 **2~4덩어리**로 나눈다. 실제로 숨을 쉬는 자리에서 끊는다.
- 각 덩어리는 `[한자, 병음]` 쌍.
- **덩어리의 글자를 모두 이으면 `zh`와 같아야 한다.** 검증기가 가장 자주 잡아내는 오류다.
- 문장부호는 넣어도 되고 빼도 된다. 기존 회차는 덩어리 **사이의 쉼표와 끝의 마침표를 뺀다** —
  `["来来来，别客气", …], ["今天这顿", …]` 처럼. 검증기도 부호를 걷어 내고 글자만 견준다.

### notes — 표현 설명

- `k`는 반드시 이 중 하나: `word` · `expr` · `grammar` · `measure` · `pron` · `culture` · `idiom`
- 한 줄에 1~2개. 모든 줄에 붙일 필요는 없지만, 새 표현이 나온 줄에는 반드시 붙인다.
- `tip`에 **확장형과 대비**를 적는다. 「食事에는 次가 아니라 顿」처럼 헷갈리는 짝을 짚어 주는 것이 좋다.

## keys — 핵심 표현

```json
{ "zh": "A是A，可是…", "py": "A shì A, kěshì…", "ko": "~하긴 한데, 다만",
  "ex": "贵是贵，可是质量确实好。", "exPy": "Guì shì guì, kěshì zhìliàng quèshí hǎo.",
  "exKo": "비싸긴 비싼데 품질은 확실히 좋아요." }
```

- 6~8개. 그 회차에서 **통째로 입에 붙여야 할 골격**을 모은다.
- 예문(`ex`)은 대화에 나온 문장이 아니라 **다른 상황에 옮긴 문장**으로 쓴다.
  같은 골격이 다른 자리에서도 쓰인다는 걸 보여 주는 것이 목적이다.

---

## out — 말하기 과제

```json
{ "q": "상대가 계산하겠다고 할 때, 두 번 사양했다가 다음을 기약해 보세요.",
  "hint": "您太见外了 / 上回就是您结的账 / 改天我做东" }
```

- 3개. 질문은 한국어, 힌트는 써야 할 중국어 표현을 `/`로 나열한다.
- **상황을 주고 말하게 한다.** "~를 중국어로 말해 보세요"가 아니라
  "상대가 ~라고 할 때 어떻게 받아치겠습니까"로 묻는다. 그래야 실제 대화에 가깝다.
