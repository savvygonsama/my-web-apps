# 스틸링고 Pro 회차 데이터 형식

앱 안의 `const DATA = [ ... ]` 배열에 들어가는 객체 하나의 명세다.
아래 예시는 실제 1회차(가격·계약)에서 그대로 가져왔다. 현재 15회차까지 있다.

이 앱은 **일본 거래처와 일하는 실무자**를 위한 것이다. Lite가 뉴스로 일본어를 익히는 곳이라면,
여기는 **상담 테이블에서 실제로 오가는 말**을 익히는 곳이다. 그래서 회차 하나가 장면 하나다.

## 최상위 필드

```js
{
  no: 16,                     // 회차 번호
  date: "8월 31일",           // 학습 예정일 표시용
  theme: "가격·계약",          // 장면 분류
  minutes: 20,                // 예상 학습 시간(분)
  terms: [...], sentences: [...], article: {...},
  dialogue: {...}, quiz: [...], column: {...}
}
```

회차 하나가 **장면 하나**다. "가격 인상을 요청하는 자리", "납기 지연을 사과하는 자리",
"클레임을 받는 자리" 처럼, 실무자가 실제로 마주치는 상황 단위로 끊는다.
소재를 여러 개 섞으면 용어가 흩어지고 대화가 겉돈다.

## terms — 오늘의 용어 8개

```js
terms: [
  { jp: "引合い", kana: "ひきあい", mean: "인콰이어리, 구매 문의",
    note: "「引合いをいただく」 형태로 씁니다. 견적 요청이 들어온 단계이고 아직 발주는 아닙니다.",
    where: "예문 1 · 회화 1턴 · 퀴즈 5",
    ez: ["引合[ひきあ]いをいただきました。", "인콰이어리를 받았습니다."] },
  // ... 모두 8개
]
```

| 필드 | 내용 | 주의 |
|---|---|---|
| `jp` | 용어 표기 | **대괄호를 넣지 않는다.** `sentences[i].drill`과 글자 그대로 같아야 한다 |
| `kana` | 읽기 | 히라가나 |
| `mean` | 한국어 뜻 | 업계에서 실제로 쓰는 말로 |
| `note` | 한 문단 설명 | 어떤 동사와 붙는지, 어느 단계에서 쓰는지 |
| `where` | 이 용어가 나오는 자리 | `"예문 1 · 회화 3턴 · 퀴즈 2"` 형식. 실제와 맞아야 한다 |
| `ez` | 초급용 짧은 문장 (선택) | `[일본어, 한국어]` 두 칸 배열. 앱의 초급 모드에서 이걸 대신 보여 준다 |

`note`가 이 앱의 값어치다. 뜻만 적지 말고 **어떤 동사와 붙어 다니는지, 어느 단계의 말인지**를 알려 줘라.
「単価を詰める」, 「引合いをいただく」처럼 짝으로 외워야 상담 자리에서 입에서 나온다.

`ez`는 앞쪽 서너 개 용어에만 붙이면 충분하다. 초급 모드에서 긴 경어 문장 대신 보여 주는 것이라,
**한 호흡에 말할 수 있는 길이**로 짧게 쓴다.

## sentences — 용어마다 실무 문장 1개

`terms`와 **1:1, 같은 순서**로 8개.

```js
{
  drill: "転嫁",                              // terms[i].jp 와 완전히 같아야 함
  jp: "原料価格[げんりょうかかく]の上昇分[じょうしょうぶん]を《転嫁[てんか]》させていただきたく存[ぞん]じます。",
  ko: "원료 가격 상승분을 반영하고자 합니다.",
  tip: "가격 인상을 꺼낼 때 쓰는 정중한 형태입니다. 「〜させていただきたく存じます」는 내 쪽 행동을 최대한 낮춘 말투입니다."
}
```

- Lite와 달리 **문장을 조각내지 않는다.** `parts`가 없다. 통문장으로 익히는 구조다.
- `jp`는 그대로 메일이나 상담에 쓸 수 있는 **완성된 경어 문장**이어야 한다. 교과서 예문이 아니다.
- `tip`은 그 문장의 **쓰임새**를 알려 준다. 왜 이 말투인지, 어느 자리에서 쓰는지.
  「〜次第で」처럼 조건부로 문을 열어 두는 장치, 부정 의문형으로 부드럽게 만드는 요령 같은 것.

## article — 기사 지문

```js
article: {
  real: true,
  source: "日本経済新聞 「トヨタ、鋼板価格据え置き 部品会社向け、下げ止まり 日鉄と妥結」",
  url: "https://www.nikkei.com/article/...",
  note: "아래 지문은 위 보도 내용을 학습용으로 요약해 다시 쓴 것입니다. 기사 원문 그대로가 아닙니다.",
  body: "トヨタ自動車[じどうしゃ]は、{2026年度}[にせんにじゅうろくねんど]上期[かみき]の…",
  lines: [ { jp: "…(후리가나 없는 원문)", ko: "…(한국어 번역)" } ],
  // 기사에 나온 표현을 따로 뽑아 두는 목록이 이어진다
  // { jp:"〜した形だ", read:"〜したかたちだ", ko:"…", from:"反映した形だ" }
}
```

**여기가 이 앱에서 가장 조심할 자리다.**

- `real: true`로 쓰려면 **실제 보도가 있어야 한다.** 웹 검색으로 확인하고 매체·제목·URL을 채운다.
- `body`는 그 보도를 **학습용으로 다시 쓴 것**이다. 원문 복사가 아니다. `note`로 그 사실을 밝힌다.
- 숫자는 원 보도의 숫자를 그대로 옮긴다. 반올림하거나 각색하지 않는다.
- 확인된 보도를 못 찾으면 `real: false`로 두고 **가상 사례임을 밝힌다.** 회사명과 수치를
  그럴듯하게 지어내 실제인 것처럼 쓰지 않는다. 사용자가 가장 싫어하는 일이다.
- `body`에는 후리가나 표기를 넣고, `lines`의 `jp`에는 넣지 않는다(대조용 원문이다).
- 연도·분기·기수는 반드시 `{2026年度}[にせんにじゅうろくねんど]`, `{4四半期}[よんしはんき]` 형태로 읽기를 단다.

## dialogue — 상담 대화

```js
dialogue: {
  situation: "보낸 견적서를 두고 고객(일본계 자동차사 조달 담당)이 단가에 이의를 제기합니다.",
  turns: [
    { me: false, jp: "…", ko: "…" },                         // 상대 턴 — ch 없음
    { me: true,  jp: "…", ko: "…",
      ch: [ ["감사합니다", "ありがとうございます。"],
            ["불명확한 점은", "ご不明[ふめい]な点[てん]は"] ] },   // 내 턴 — ch 필수
    // ... 보통 8턴, false로 시작해 번갈아
  ],
  warns: [
    { hard: true,  head: "✗ 「できません」 (할 수 없습니다)",
      body: "너무 직설적이라 대화가 거기서 끊깁니다. 「難しい」로 받은 뒤 반드시 대안을 붙입니다." },
    { hard: false, head: "△ 마지막 턴을 생략하지 말 것", body: "…" }
  ]
}
```

- `me: false`는 상대(거래처), `me: true`는 나. 상대로 시작해 번갈아 간다.
- **`ch`는 내 턴에만 붙인다.** 한국어를 보고 일본어를 떠올리는 연습용이라, `[한국어 조각, 일본어 조각]`
  쌍으로 나눈다. 일본어 조각을 모두 이으면 그 턴의 `jp`와 정확히 같아야 한다.
- `warns`는 이 장면에서 **한국인이 실제로 저지르는 실수**를 잡아 준다. `hard: true`는 하지 말아야 할 것,
  `false`는 놓치기 쉬운 것. 2~3개 넣는다. 이 앱을 교재가 아니라 실무 도구로 만드는 부분이다.
- 대화는 **당일 결론이 나지 않는 것이 정상**이다. 마지막 턴에서 다음 확인 시점을 못박고 끝낸다.

## quiz — 6문항

두 가지 형태를 섞는다.

```js
quiz: [
  { q: "「据え置き」의 뜻은?", opts: ["인상", "인하", "동결 (유지)"], ans: 2 },   // 객관식
  { q: "「妥結」을 히라가나로 쓰면?", answer: "だけつ" },                        // 주관식
  { q: "\"단가에 대해서는 수량에 따라 조정의 여지가 있습니다\"를 일본어로.",
    answer: "単価につきましては、数量次第で調整の余地がございます。" }
]
```

- 객관식은 `opts` 3개 + `ans`(0부터 세는 번호). 주관식은 `answer` 하나.
- 6문항 중 2~3개는 주관식으로 두면 좋다. 고르는 것과 쓰는 것은 다른 근육이다.
- **뜻만 묻지 마라.** 기존 회차의 좋은 문항은 이런 것이다 —
  「この単価では難しい状況です」라고 했을 때 상대의 진짜 의미는 무엇인가.
  용어를 아는지가 아니라 **상담을 읽는지**를 묻는다.

## column — 마무리 칼럼

```js
column: {
  word: "検討", kana: "けんとう", ko: "검토",
  title: "「検討します」를 검토로 들으면 안 됩니다",
  body: [ "문단 1 …", "문단 2 …", "문단 3 …" ],
  note: "…"
}
```

- 그 장면에서 **한국인이 오해하기 쉬운 말 하나**를 골라 푼다.
  한국어에 같은 한자어가 있어서 뜻이 통한다고 믿었다가 어긋나는 말이 가장 좋은 소재다.
- 낱말 강조는 `<span class='kw'>검토</span>`, 일반 강조는 `<b>`.
- 3문단. 마지막 문단은 **그래서 실무에서 어떻게 받아쳐야 하는지**로 닫는다.
