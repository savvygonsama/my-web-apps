# ことば日和 회차 데이터 형식

앱 안의 `const DAYS = [ ... ]` 배열에 들어가는 객체 하나의 명세다.
아래 예시는 실제 1일차(気持ちのことば)에서 그대로 가져왔다.

**후리가나 표기를 직접 쓰지 않는다.** 일본어는 평범하게 쓰고, 읽기는 `kana` 필드에 따로 적는다.
앱이 둘을 맞물려 화면에서 루비를 만든다.

## 최상위 필드

```js
{
  no: 31,
  theme: "気持ちのことば",        // 일본어 주제명
  themeKo: "마음을 말하는 말",     // 한국어 주제명
  lv: "N3",
  words: [...], root: "気", rootKo: "...", branches: [...],
  quiz: [...], bunka: {...}
}
```

`theme`은 그날 배우는 말들을 한 묶음으로 부르는 이름이다.
문법 항목이 아니라 **뜻의 묶음**으로 잡는다 — "마음을 말하는 말", "사람과 어울리는 말" 처럼.

## words — 단어 10개

```js
words: [
  { ja: "気になる", kana: "きになる", ko: "신경 쓰이다, 마음에 걸리다",
    exs: [
      { s: "さっきの話が気になって、眠れなかった。", t: "아까 그 이야기가 신경 쓰여서 잠을 못 잤다." },
      { s: "テストの結果が気になります。", t: "시험 결과가 신경 쓰입니다." },
      { s: "実は、あの人のことがちょっと気になっている。", t: "실은 저 사람이 좀 마음에 든다." }
    ],
    note: "걱정으로도, 호감으로도 씁니다. 세 번째 예문처럼 사람에게 쓰면 \"마음이 간다\"는 뜻이 됩니다." }
  // ... 모두 10개
]
```

| 필드 | 내용 | 주의 |
|---|---|---|
| `ja` | 일본어 표기 | 후리가나 표기를 쓰지 않는다. `気になる` (○) / `気[き]になる` (×) |
| `kana` | 전체 읽기 | 히라가나. **표기와 맞물려야 한다** — 아래 참고 |
| `ko` | 한국어 뜻 | 여러 뜻은 쉼표로 |
| `exs` | 예문 **2~3개** | `{ s: 일본어, t: 한국어 }` |
| `note` | 한 문단 설명 | 함께 쓰는 형태, 헷갈리는 말과의 차이 |

### 표기와 읽기가 맞물린다는 것

앱은 `ja`와 `kana`를 대조해 한자 덩어리마다 읽기를 나눠 준다.

```
落ち着く + おちつく  →  落=お · ち · 着=つ · く      ✓ 맞물림
```

한자가 아닌 글자(`ち`, `く`)가 양쪽에 똑같이 나타나기 때문에 경계를 잡을 수 있다.
이 대응이 깨지면 앱은 그 말에 후리가나를 붙이지 못한다. 검증기가 같은 알고리즘으로 확인한다.

흔한 실수는 **읽기를 축약하거나 표기에 없는 글자를 넣는 것**이다.
`ja: "気を使う"` 에는 `kana: "きをつかう"` 가 맞다. `を`를 빠뜨리면 어긋난다.

### 예문 쓰기

- 2~3개. 세 개를 쓸 때는 **쓰임의 폭을 보여 주는 순서**로 놓는다.
  기본 용법 → 정중형 → 뜻이 살짝 다른 용법.
- 예문은 그 단어가 실제로 사는 자리여야 한다. 문법 연습용 문장이 아니다.
- 마지막 예문에 회화체 짧은 형태(「気をつけて。」)를 넣으면 실전에 붙는다.

## root / branches — 뿌리에서 뻗은 말들

```js
root: "気",
rootKo: "「気」로 뻗어나가는 말들 — 마음의 움직임을 나타내는 뿌리입니다",
branches: [
  { ja: "気を使う", kana: "きをつかう", ko: "신경 쓰다, 배려하다",
    note: "상대를 위해 마음을 쓰는 것. 오늘 토막 상식의 주인공입니다." },
  { ja: "元気 / 人気", kana: "げんき / にんき", ko: "건강함·활기 / 인기",
    note: "「気」가 들어간 가장 익숙한 두 단어. 뿌리가 같다는 걸 알면 기억이 붙습니다." }
  // 보통 6개
]
```

이 앱의 성격을 만드는 부분이다. 단어를 낱개로 외우는 대신 **한자 하나에서 갈라져 나온 가족**으로 본다.

- `root`는 한자 **한 글자**. `words`에 여러 번 나온 한자를 고르면 자연스럽게 이어진다.
- `branches`는 보통 **6개**. `words`에 이미 나온 말은 넣지 않는다 — 새로 뻗는 가지여야 한다.
- `note`는 짧게. 뜻보다 **왜 이 말이 그 뿌리에서 나왔는지**, 혹은 헷갈리는 짝을 짚어 준다.
- `ja`에 `"元気 / 人気"`처럼 둘을 묶어도 된다. 그때는 `kana`도 `"げんき / にんき"`로 맞춘다.

## quiz — 6문항

```js
quiz: [
  { q: "「気になる」の意味は？", opts: ["신경 쓰이다", "마음에 들다", "기분 탓이다"], a: 0 },
  { q: "確信がないときに文末につける表現は？", opts: ["気がする", "気をつける", "気が合う"], a: 0 },
  { q: "「먹고 싶지만 오늘은 참는다」— 빈칸은?　食べたいけど、今日は（　　）。",
    opts: ["我慢する", "緊張する", "落ち着く"], a: 0 }
]
```

- `opts` 3개, `a`는 0부터 세는 번호. (스틸링고는 `ans`인데 이 앱은 `a`다. 헷갈리지 마라.)
- 질문은 **일본어와 한국어를 섞어** 쓴다. 뜻을 묻는 문항은 일본어로, 상황을 주는 문항은 한국어로.
- 6문항 안에 세 종류를 고루 넣는다 — 뜻 고르기, 상황에 맞는 말 고르기, 빈칸 채우기.
- 오답 보기는 그날 배운 말에서 고른다. 틀려도 복습이 된다.
- 전각 공백 `　`으로 빈칸을 표시한다.

## bunka — 문화 칼럼

```js
bunka: {
  cap: "ちょっと日本",
  title: "「気を使う」と韓国の「눈치」",
  titleKo: "닮은 듯 방향이 반대인 두 말",
  body: [ "문단 1 …", "문단 2 …" ],
  vs: "「彼は気を使う人だ」 → <b>배려심이 깊은 사람</b>이라는 칭찬<br>「그는 눈치가 빠르다」 → <b>상황 파악이 빠른 사람</b>이라는 평가",
  body2: [ "문단 3 …", "문단 4 …" ],
  sign: "송일본 · 도쿄 거주 35년"
}
```

가장 공들일 자리다. 좋은 소재는 **한국어에 같은 말이 있어서 통한다고 믿었다가 어긋나는 지점**이다.

- `cap`은 고정 캡션(`"ちょっと日本"`).
- `body` 2문단 → `vs` 한 줄 대조 → `body2` 2문단. 이 리듬을 지킨다.
- `vs`는 두 언어를 나란히 놓고 **방향이 어떻게 다른지** 한눈에 보여 주는 줄이다. `<br>`로 나눈다.
- `body2`의 마지막 문단은 **그날 배운 단어와 다시 이어 준다.**
  1일차가 「我慢する」로 돌아가 닫는 것처럼.
- 낱말 강조는 `<span class='kw'>말</span>`, 일반 강조는 `<b>`.
- `sign`은 필자 서명. 기존 회차의 것을 그대로 쓴다.
- **문화 이야기를 지어내지 마라.** 확실히 아는 것만 쓰고, 애매하면 그 소재를 버린다.
  좋고 나쁨을 판정하지 말고 "말 속에 그런 감각이 굳어 있다"는 선에서 멈추는 것이 이 칼럼의 태도다.
