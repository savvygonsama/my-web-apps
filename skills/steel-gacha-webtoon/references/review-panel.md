# 5인 패널 검토

사용자가 정한 방식: **독립 검토자 5명, 최대 3라운드, 5인 평균 9.8 이상 + 전원 9.5 이상이면 합격.**
검토자는 산출물을 만들지 않은 별도 에이전트로 띄우고, 서로의 점수를 모른 채 병렬로 채점한다. 매 라운드 새로 채점한다.
3라운드 후에도 미달이면 점수를 올려 적지 않고, 받은 점수와 남은 결함을 그대로 보고한다.

## 검토자
| 검토자 | 보는 것 |
|---|---|
| 문서·품질 검수 (의장) | 요구사항 완결, 문서 간 불일치(대사·설정·순서), 작화 단순도, 사용자가 바로 다음 행동을 할 수 있는가 |
| 비판적 검토자 | 컷4가 정말 '피식'인가, 펀치가 미리 새는가, 클리셰·설명형 개그, "이 연재가 왜 실패하는가" 반론 |
| 철강 현업 감수자 | 강종 특성 근거, 철강·앱 사실 오류, 현업 공감("우리 얘기다"), 안전·선 넘는 소재 |
| 웹툰 편집자 | 4컷 호흡, 컷 정보량(말풍선 실측), 말투 블라인드 테스트, 2×2 프롬프트가 실제로 단순한 그림을 뽑는가, 시리즈성 |
| 일반 독자 (철강 모르는 30대 회사원) | 첫 1초 이해, 각주를 가리고 본 컷4 반응, 편안함, 캐릭터 호감·이름 기억 |

## 검토자 공통 규칙
- 불합격을 기본값으로 두고 결함부터 찾는다. 칭찬 금지.
- 결함마다: 위치(문서·EP·컷) / 문제 / 고칠 방향 한 줄 / 책임 단계 / 심각도(치명·중·경). 사실 오류는 최소 '중'.
- 0~10점 한 개. 9.5 이상이면 "떨어질 뻔한 지점 1개와 넘긴 근거"를 적는다.
- 일반 독자는 '철강 포인트' 각주를 먼저 가리고 읽은 뒤, 각주를 보고 반응이 달라지는지 적는다.

## 팀장(오케스트레이터) 규칙
- 검토자끼리 갈린 지적은 팀장이 결정해 '보강 지시서'로 확정하고, 결함을 만든 단계 담당에게 돌려보낸다.
- 보강은 결함을 고치는 일이다. 문서 순증은 원본 대비 10% 이내.
- 단계 순서대로 보강한다(바이블 → 콘티 → 작화). 1라운드 실패의 큰 원인이 문서 간 불일치였다.

## 1라운드에서 배운 것 (평균 7.4)
| 실패 | 교훈 |
|---|---|
| 다섯 편 컷4가 모두 훈훈한 정리로 착지 | 컷4는 뒤집기. 다정함은 펀치 자리에 두지 않는다 |
| 이지 펀치 "밖은 출근, 안은 퇴근" | 그림(좌우)과 대사(안팎)의 좌표가 다르면 철강을 알아야 웃긴다 |
| 펀치가 비유를 말로 정리("세수하자마자 로션이네") | 독자가 이미 떠올린 것을 확인해 주는 건 요약이지 펀치가 아니다 |
| 자정까지 기다리는 앱 개그 | 앱 사용자는 퀴즈·알림으로 바로 반박한다. 앱 사실 구멍을 막는다 |
| 조끼 소품이 컷1부터 이유 없이 등장 | 펀치 소품은 셋업이 있어야 한다 |
| 반창고 + "머리 쾅" | 일하다 다친 장면으로 읽힌다 |
| 야외 코일, 받침 없는 코일 | 업계 독자는 웃기 전에 "코일을 밖에 둬?"부터 한다 |
| 주연 이름이 컷 안에서 한 번도 안 불림 | 첫 등장 이름표 자막 |
| 타래·씨알 대사가 블라인드 테스트에서 겹침 | 말투 표지를 매 줄 강제 |
| 도금이가 착한 구경꾼으로 끝남 | 바이블의 개그 역할이 콘티에서 실제로 작동해야 한다 |
| 대표 5편 순서가 시즌 흐름과 달라 첫 방문 전 등장 | 파일럿 = 시즌 1~5화로 정본을 하나로 |
