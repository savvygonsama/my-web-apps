# 스틸 그레이드 가챠 4컷 웹툰

앱 `savvygonsama/steel-grade-gacha`의 강종 캐릭터로 만드는 일상 개그 4컷.
**Claude가 기획·콘티·프롬프트를 쓰고, 그림은 사용자가 ChatGPT 이미지 생성으로 뽑는다.**

| 참조 | 내용 |
|---|---|
| `references/characters.md` | 캐릭터 바이블 요약: 개그 역할, 말투 규칙, 그림 키, 조연 규칙 |
| `references/steel-facts.md` | 철강·앱 사실 함정과 정정 목록, 선 넘는 소재 |
| `references/art-prompts.md` | 작화 원칙, 팔레트, 캐릭터 시트·배경·에피소드 프롬프트 틀, ChatGPT 사용 순서 |
| `references/review-panel.md` | 5인 패널 검토 기준과 합격선, 1라운드에서 배운 것 |
| `references/episodes.md` | 시즌 1 파일럿 5편 라인업과 확정 콘티 |

## 독자와 톤

- 주 독자는 **철강 업계 사람 + 앱 사용자**. 그러나 **철강을 몰라도 웃겨야 한다.** 철강 지식은 양념이고 웃음이 주재료다.
- 평화롭고 다정한 일상 개그. 목표 반응은 '흐뭇'이 아니라 **'피식'**.
- 그림은 부담 없이 볼 만큼 단순하게.

## 절대 규칙

### 4컷 원칙 (가장 중요)
1. **컷1 상황 → 컷2 전개 → 컷3 기대 쌓기 → 컷4 뒤집기.** 펀치를 컷2·3에 흘리지 않는다.
2. **컷4는 독자가 예상 못 한 한 칸이다.** 다정함은 컷3이나 컷4 구석의 작은 결과로 남기고, 펀치 자리에 두지 않는다. "훈훈하게 정리하며 끝"은 3화쯤이면 공식이 읽혀 실패한다.
3. **컷4를 캐릭터가 비유를 말로 정리하는 방식으로 끝내지 않는다**("~하자마자 ~이네" 같은 요약 대사 금지). 묶음마다 최소 40%는 대사 없음(또는 한 단어) + 그림 반전으로 끝낸다.
4. **철강 용어가 펀치의 열쇠가 되면 안 된다.** 몰라도 웃기고, 알면 각주에서 한 번 더 웃게.
5. **그림과 대사의 좌표를 맞춘다.** 그림이 좌우로 나뉘면 대사도 좌우나 색으로 말한다(이지 "밖/안" 실패 사례).
6. 펀치에 쓰는 소품은 앞 컷에 미리 심는다(셋업 없는 소품 금지).
7. 제목이 펀치를 미리 말하지 않는다.

### 컷 정보량
- 컷당 등장인물 **2명 이하**(3명은 시즌에 한두 번 예외로만, 콘티에 사유 명시).
- 한 컷에 **행동 하나**.
- 말풍선 하나 **한국어 25자 안팎**, 컷당 **2개 이하**, 한 편 합계 **6개 이하** 권장.
- 배경은 반복 배경 3개 중 하나, 소품 1~2개.

### 캐릭터·말투
- 말투 블라인드 테스트를 통과해야 한다: **대사만 가려도 누군지 알 수 있게.** 세부는 `references/characters.md`.
  - 타래 대사엔 매 줄 **물음표나 '뾰잉'**.
  - 씨알 대사엔 **숫자·기준**.
  - **'~잖아' 어미는 도금이 전용.**
  - 포오는 짧은 반말·느낌표 없음. 이지는 주연 중 유일한 해요체(웹툰 연출상 말투 변경).
- 각 캐릭터가 시리즈에서 **처음 나오는 컷에 작은 이름표 자막**("포오 · 산세강판"). 대사로도 이름을 한 번 부른다.
- 캐릭터는 모두 **성별 없음**. 형·오빠·누나·언니·자매 같은 호칭 대신 **이름으로 부른다**(같은 종족 관계는 '같은 집', '막내'처럼 성별 없는 말로). 영어 프롬프트에서는 he/she/his/her 대신 이름을 쓴다.
- 바이블의 개그 역할이 콘티에서 실제로 작동해야 한다(도금이가 '착한 구경꾼'으로만 끝나면 실패).

### 무대
- **지붕 있는 출하동 셔터 앞**과 **견본실**, **도감판 벽** 세 곳. 날씨는 열린 셔터 너머로만 보인다.
- 냉연·도금 코일은 **실내, V자 받침(새들) 위**. 인물은 **노란 보행선 안쪽**에서만 움직인다. 코일 옆에서 뛰어다니지 않는다.

### 철강·앱 사실
- 사실 오류 금지. 작성 전 `references/steel-facts.md` 함정 목록을 확인한다.
- **앱 사실과 어긋나는 개그 금지**: 뽑기는 마지막으로 뽑은 시각부터 24시간 뒤에 열리고 버튼에 남은 시간이 뜬다. 퀴즈 정답으로 24시간에 3번까지 뽑기가 추가된다(하루 최대 4번). 뽑기 시간 알림이 있다. 큐피는 뽑기로 안 나오고 1470급 셋을 모아야 열린다.
- 실명·실존 회사·브랜드·사고·노사·외모·나이·성별 소재 금지. 일하다 다치는 장면(반창고 등) 금지.

### 각주
- 에피소드 아래 '철강 포인트'는 **한 줄, 약어 없이**(PO·EG·CHQ·MPa 쓰지 않기), 접어 두는 각주로.

## 작업 흐름

### A. 새 에피소드 한 편 ("N화 만들어 줘")
1. `references/episodes.md`에서 라인업·앞 화와의 연결을 확인한다. 새 소재면 캐릭터 2명과 무대 하나를 고른다.
2. 콘티를 아래 형식으로 쓴다.
3. 절대 규칙 체크리스트로 스스로 점검한다: 컷4 뒤집기 / 펀치가 철강 용어에 기대지 않음 / 말풍선 25자·2개 / 컷당 2명 / 말투 표지 / 첫 등장 이름표 / 사실 함정 / 앱 사실.
4. `references/art-prompts.md`의 틀로 ChatGPT 프롬프트를 쓴다. 대사를 이미지에 넣는 기본 프롬프트 + 글자가 깨질 때의 빈 말풍선 대체 문장 + 한 컷만 다시 그리기 문장을 함께 준다.
5. 새 캐릭터가 처음 나오면 그 캐릭터의 시트 프롬프트와 원본 그림 파일(`steel-grade-gacha/src/img/`)을 함께 준다.

콘티 형식:
```
### EP.N 제목 (펀치를 미리 말하지 않는 제목)
로그라인 한 줄 / 중심 인물 / 웃음 유형
컷1 [장면] 누가·어디서·무슨 동작 하나 (2명 이하)
     [대사] 캐릭터: "..." (25자 안팎, 2개 이하)
     [자막] 첫 등장이면 "이름 · 소재"
컷2 ...
컷3 ... (기대 쌓기, 펀치 미리 흘리지 않기)
컷4 ... ← 뒤집기
철강 포인트(접어 두기, 한 줄, 약어 없이)
```

### B. 여러 편·시즌 기획
캐릭터 바이블 → 소재 풀 → 파일럿 콘티 → 작화 프롬프트 순서로, 단계마다 별도 담당을 두고 `references/review-panel.md`의 5인 패널로 검토한다. 사용자가 정한 기준: **5인 평균 9.8 이상 + 전원 9.5 이상, 최대 3라운드.** 3라운드 후에도 미달이면 점수를 올려 적지 않고 남은 결함과 점수를 그대로 보고한다.

### C. ChatGPT에 넘길 때
- 새 대화창 하나에서 **캐릭터 시트 → 배경 → 에피소드** 순서.
- 시트에는 원본 피규어 그림을 첨부한다.
- 새 창에서 이어 할 때는 저장한 시트·배경 이미지를 **직접 첨부**한다. 앞에서 만든 것을 말로 부르는 방식은 대화가 길어지면 흐려진다.
- 한 화에 필요한 시트·배경만 보내는 **화별 최소 경로**를 안내한다(예: EP.1 = 포오 시트 + 씨알 시트 + 견본실).
